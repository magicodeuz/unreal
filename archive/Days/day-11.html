Stage 2 · Kun 11 / 14

Crouch

Egilib yurish: Capsule qisqaradi, tezlik pasayadi, kamera silliq pastga tushadi. Betray Builder’da vent / past eshik / yashirinish uchun asos.

🎯 Kun maqsadi

Bugun oxirida o‘yinchida quyidagilar bo‘lishi kerak:

  • → Left Ctrl bosib turilganda Character egiladi (Crouch)
  • → Capsule balandligi avtomatik kamayadi — past joylardan o‘tish mumkin
  • → Yurish tezligi crouch paytida sekinroq
  • → Kamera keskin sakramaydi — Interp / Timeline bilan silliq pastga
  • → Ctrl qo‘yib yuborilganda UnCrouch + kamera asl holatga
  • → IsCrouching state saqlanadi
  • → (Challenge) Crouch paytida Sprint ishlamaydi

Bugun qilmang: Crouch skeletal animatsiyasi (Animation stage — ~Kun 80). Hozir faqat collision + kamera + speed. Mesh T-pose’da “cho‘kishi” shart emas.

? Nima uchun bu kun muhim?

Betray Builder social deduction / map exploration o‘yini. Past ventlar, stol osti, tor koridorlar — o‘yinchi egilmasa o‘tolmaydi. Shu bilan birga:

  • Capsule o‘zgarmasa, “egilgan” ko‘rinsa ham collision to‘liq balandlikda qoladi — eshikdan o‘tmaydi.
  • Kamera birdan pastga tushsa, o‘yinchi ko‘zi charchaydi / orientatsiya yo‘qoladi.
  • Sprint + Crouch birga bo‘lsa, “egilib yugurish” g‘alati va keyinroq stamina/balance buziladi — shuning uchun challenge’da cheklaymiz.

UE Character Movement allaqachon Crouch / UnCrouch beradi — biz uni inputga ulaymiz va kamerani qo‘lda moslashtiramiz.

📖 Asosiy tushunchalar (batafsil)

Crouch / UnCrouch (Character)

Character class’dagi tayyor funksiyalar. Ichida: “Can Crouch?” tekshiruvi, Capsule half-height o‘zgarishi, Movement mode flag’lari. Siz faqat chaqirasiz — capsule matematikasi UE ichida.

Crouched Half Height

Character Movement Component parametri. Oddiy holda Half Height = 96 (to‘liq ~192). Egilganda masalan 60 — sezilarli pastroq, lekin “yassi” emas. Juda kichik qiymat (20) Mesh va kamera bilan chalkashadi; 48–64 diapazon odatda qulay.

Nav Agent / Can Crouch

Character Movement’da Can Crouch (yoki Nav Movement / crouch ruxsati) yoqilgan bo‘lishi kerak. Default ko‘pincha true; ishlamasa shu yerni tekshiring.

Max Walk Speed Crouched

Egilganda alohida tezlik. Masalan 150–200. Crouch() chaqirilganda Movement shu qiymatga o‘tadi (sozlangan bo‘lsa). Yo‘qsa oddiy Max Walk Speed ishlashi mumkin — aniqroq uchun alohida maydonni to‘ldiring.

Kamera: nima uchun alohida?

Capsule qisqarganda SpringArm/Camera avtomatik “bosh balandligi”ga tushmaydi. Relative Location Z ni o‘zgartirmasangiz, kamera yuqorida qoladi yoki g‘alati burchakda turadi. Birdan Set Relative Location qilsangiz — keskin sakrash. Shuning uchun FInterp To (Tick’da) yoki Timeline (0→1 float) ishlatiladi.

FInterp To vs Timeline

FInterp To: har Tick joriy Z ni maqsad Z ga yaqinlashtiradi (Interp Speed). Oddiy, kam node. Timeline: aniq egri (curve) va vaqt (0.2–0.35 s). Ko‘proq nazorat, biroz ko‘proq sozlash. Bugun ikkalasidan birini tanlang — ikkalasi ham to‘g‘ri.

1.1 Component’ni ochish

BP_Player → Components → Character Movement tanlang.

Details panelida qidiruvga yozing: Crouch — barcha bog‘liq maydonlar filtrlanadi.

1.2 Tavsiya etilgan qiymatlar
Parametr Qiymat Izoh
Can Crouch / Nav Can Crouch ✓ true Ruxsat
Crouched Half Height 60 96 dan past
Max Walk Speed Crouched 180 Yurishdan sekin

Agar “Max Walk Speed Crouched” topilmasa — Character Movement → Walking guruhida qidiring yoki umumiy Max Walk Speed crouch paytida qo‘lda Set qilasiz (keyinroq).

2

IsCrouching va kamera maqsadlari

Taxminiy vaqt: 10 daqiqa

2.1 Variables

My Blueprint → Variables. Quyidagilarni qo‘shing:

Nom Tip Default / ma’no
IsCrouching Boolean false
StandingCameraZ Float Asl SpringArm/Camera Z (masalan 60)
CrouchCameraZ Float Pastroq (masalan 20 yoki 0)
TargetCameraZ Float Joriy maqsad (Interp uchun)

BeginPlay’da:

  • StandingCameraZ = SpringArm Get Relative Location → Z (yoki qo‘lda yozgan qiymat)
  • TargetCameraZ = StandingCameraZ
  • CrouchCameraZ ni Standing’dan ~30–50 pastroq qiling (sinab ko‘ring)

Compile.

3

IA_Crouch → Crouch / UnCrouch

Taxminiy vaqt: 15 daqiqa

3.1 Event node

Event Graph → IA_Crouch (Enhanced Input Action).

Kun 6 dagi Print bo‘lsa — o‘chiring yoki o‘rniga haqiqiy mantiq yozing.

3.2 Started 
Started
  → Crouch          // Character function, Target = Self
  → Set IsCrouching = true
  → Set TargetCameraZ = CrouchCameraZ

Crouch node qidiruvda “Crouch” — Character Movement / Pawn bo‘limida.

3.3 Completed 
Completed
  → UnCrouch
  → Set IsCrouching = false
  → Set TargetCameraZ = StandingCameraZ

Bosh ustida to‘siq: UnCrouch ba’zan “joy yetarli emas” deb bekor qilinadi (shift ustida). Bu normal. Keyinroq “crouch hold until clear” murakkabroq mantiq — bugun oddiy Completed yetarli.

4

Kamera silliq pastga / yuqoriga

Taxminiy vaqt: 25–35 daqiqa · eng muhim qism

4.1 Qaysi component?

Odatda SpringArm Relative Location Z o‘zgartiriladi (kamera uning child’i — birga tushadi).

Agar kamera to‘g‘ridan-to‘g‘ri Capsule’da bo‘lsa — Camera Relative Z.

Components’da SpringArm’ni tanlab, hozirgi Location Z ni StandingCameraZ bilan solishtiring.

4.2 Usul A — Event Tick + FInterp To (tavsiya, sodda)
  1. Event Tick (yoki agar Tick o‘chirilgan bo‘lsa — Primary Actor Tick yoqing).
  2. SpringArm → Get Relative Location → Break Vector.
  3. FInterp To: Current = Z, Target = TargetCameraZ, Delta Time = Tick Delta, Interp Speed = 10 (sinab ko‘ring: 6 sekin, 15 tez).
  4. Make Vector: X va Y eski, Z = Interp natijasi.
  5. SpringArm → Set Relative Location.

Nima uchun Tick? TargetCameraZ Crouch/UnCrouch da bir marta o‘zgaradi; Tick har freym joriy joylashuvni maqsadga “tortadi”. Maqsadga yetganda deyarli to‘xtaydi (FInterp To yaqinlashadi).

4.3 Usul B — Timeline (ixtiyoriy alternativ)

My Blueprint → Timeline asset (Add Timeline). Length 0.25 s. Float track 0→1.

Crouch Started → Timeline Play; Update da Lerp (StandingCameraZ, CrouchCameraZ, Alpha) → Set Relative Z.

UnCrouch → Timeline Reverse (yoki ikkinchi yo‘nalish).

Ko‘proq ish, lekin vaqt aniq. Birinchi marta Usul A yetarli.

4.4 Qiymatlarni tanlash

Play qilib Ctrl bosing. Agar kamera:

  • Juda past — CrouchCameraZ ni biroz oshiring
  • Deyarli o‘zgarmagan — farqni kattalashtiring (Standing 60 → Crouch 15)
  • Sekin / kechikkan — Interp Speed ni 12–15 qiling
  • Keskin — Speed ni pasaytiring yoki Timeline ishlating
5

Sprint va Crouch birga ishlamasin (tayyorgarlik)

Challenge asosi · 10 daqiqa

5.1 G‘oya

IA_Sprint Started zanjirining boshida:

Started (Sprint)
  → Branch (IsCrouching?)
       ├─ True  → (hech narsa / Print "Can't sprint while crouching")
       └─ False → Set Max Walk Speed 600, IsSprinting true

Ixtiyoriy: Crouch Started da agar IsSprinting bo‘lsa — avval Sprint’ni o‘chiring (Speed 300, IsSprinting false), keyin Crouch.

Bu challenge’da to‘liq talab qilinadi; asosiy vazifa uchun kamida Sprint Started’da Branch qo‘ying.

★

Challenge — Crouch vs Sprint

Ikki state birga yashamasin

Talab:

  1. IsCrouching == true bo‘lsa, IA_Sprint Started tezlikni oshirmasin.
  2. (Qo‘shimcha) Sprint paytida Crouch bosilsa — avval sprintni to‘xtatib, keyin egiling yoki crouch’ni rad eting. Birini tanlang va izchil qiling.

Bu keyingi stamina / movement state machine uchun yaxshi odat: bir vaqtda bitta “pose”.
