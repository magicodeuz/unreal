KUN 5 / 90 STAGE 1 · FUNDAMENTALS ARXITEKTURA

Blueprint Communication

Ikki Actor qanday gaplashadi? Avval Cast, keyin Interface. Bu kun — keyingi Interaction System ning poydevori.

Bugungi aniq maqsad

Cast bilan OnActivate, keyin BPI_TestInterface va Interface Message. Ikkala obyekt — bitta kod. Line Trace chuqur emas.

01 Muammo: tight coupling

Agar Player faqat Cast to BP_Door, keyin Cast to BP_Lever, keyin Cast to BP_Chest deb yozilsa — har yangi obyekt uchun Player ochiladi. Bu tight coupling: o‘zgarish qimmat, xato ko‘p.

Interface: “Kimdir OnActivate ni bajaradi” deb va’da. Player faqat va’dani chaqiradi — kim ekanini bilishi shart emas. Shu sabab 90 kunlik kursda Interaction BPI asosida.

02 Ikki usul — yonma-yon

① Cast

Aniq tipni bilish kerak

Hit Actor
  → Cast to BP_TestObject
  → Success: Call OnActivate
  → Fail: (boshqa tip?)

Yangi tip = yangi Cast tarmoq

② Interface

Faqat “va’da” muhim

Hit Actor
  → Does Implement BPI?
  → Yes: Interface Message
        OnActivate
  → No: e'tibor bermaslik

Yangi tip = faqat implement

03 Usul 1 — avval Cast (tushunish uchun)

BP_Player (yoki Character) da vaqtincha: E bosilganda “nima qarshimizda?” deb oling (Get Hit Result / oddiy reference test ham mumkin — Line Trace chuqurligi Day 15). Cast to BP_TestObject → OnActivate.

BP_TestObject2 ga Cast qilsangiz — Fail. Shu yerda muammo seziladi.

04 Usul 2 — BPI_TestInterface

  1. Content → Interaction papka (yarating) → Blueprint Interface → BPI_TestInterface
  2. Ichiga funksiya: OnActivate (input/output hozircha bo‘sh ham bo‘ladi)
  3. BP_TestObject va BP_TestObject2: Class Settings → Implemented Interfaces → qo‘shing
  4. Har birida Interfaces → OnActivate ni implement qiling (Print)
  5. Player da: Cast o‘rniga Interface Message → OnActivate

Interface Message “jim” ishlaydi: implement qilmagan Actor da hech narsa bo‘lmaydi (xato emas). Does Implement Interface? bilan oldindan tekshirish mumkin.

05 Amaliy qadamlar

BP_TestObject2

BP_TestObject dan Duplicate yoki yangi Actor + OnActivate Print. Levelga ikkalasini qo‘ying.

2

BPI + implement

Bir kod — ikki obyekt

E (yoki test chaqiruv) ikkalasida ham OnActivate ishlatadi.

★ Professor izohi
