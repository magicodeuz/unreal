03 Yechim A — Boolean + Branch (toggle)

Qanday yig‘iladi:
1) + Variable → bIsHidden Boolean
2) IA_Interact Triggered (yoki E Pressed) → Get bIsHidden → NOT → Set bIsHidden
3) Set dan keyin Branch (Condition yana Get bIsHidden)
4) True: Hidden true + Enable Collision false
5) False: Hidden false + Enable Collision true
Node qidiruv: Set Actor Hidden, Set Actor Enable Collision
