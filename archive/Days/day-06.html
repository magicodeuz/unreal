KUN 6 / 90 STAGE 1 · FUNDAMENTALS ENHANCED INPUT

Input System

E, Shift, Ctrl endi “hard-coded tugma” emas — Input Action + Mapping Context assetlari.

Bugungi aniq maqsad

IA_Interact, IA_Sprint, IA_Crouch + IMC_BetrayBuilder. Character BeginPlay da Add Mapping Context. Faqat Print — haqiqiy Sprint/Crouch keyinroq.

01 Nima uchun Enhanced Input?

Kecha E ni to‘g‘ridan-to‘g‘ri Keyboard Event qildik. Bu ishlaydi, lekin:

  • Tugmani o‘zgartirish — kod ochish
  • Gamepad — yana boshqa event
  • Settings menyusi — qiyin

Enhanced Input: amal (Interact) va tugma (E) ajratilgan. IMC da bog‘lanadi. Keyin faqat IMC ni tahrirlaysiz.

Event Graph:
  Enhanced Input Action IA_Interact (Triggered) → Print "Interact bosildi"
  Enhanced Input Action IA_Sprint (Triggered)   → Print "Sprint bosildi"
  Enhanced Input Action IA_Crouch (Triggered)   → Print "Crouch bosildi"

Third Person template odatda allaqachon Enhanced Input ishlatadi. Mavjud IMC ga qo‘shish yoki yangi IMC ni qo‘shish — ikkalasi ham mumkin. Conflict bo‘lsa, priority ni tekshiring.

05 Amaliy qadamlar

1

Input papkasi + 3× IA

  1. Content/.../Input papka.
  2. Right-click → Input → Input Action ×3: Interact, Sprint, Crouch.
  3. Value Type odatda Digital (bool) — tugma uchun yetarli.
2

IMC_BetrayBuilder

  1. Input → Input Mapping Context.
  2. E, Left Shift, Left Ctrl ni mos IA larga bog‘lang.
3

Add Mapping Context + Events

  1. Character BeginPlay da IMC qo‘shing.
  2. Har IA uchun Enhanced Input Action event + Print.
  3. Play: E / Shift / Ctrl.
