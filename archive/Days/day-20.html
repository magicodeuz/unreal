Computer

E → Widget ochiladi, sichqoncha ko‘rinadi, Close → o‘yin qaytadi. Chiroyli UI emas — bog‘lanish tamoyili.

🎯 Kun maqsadi

  • → WBP_ComputerScreen_Placeholder — matn + Close
  • → BP_Computer + BPI_Interact
  • → Interact: Create Widget → Add to Viewport
  • → Set Input Mode UI Only + Show Mouse Cursor
  • → Close: Remove from Parent + Input Mode Game Only
  • → (Challenge) Widget ochiqda harakat o‘chiriladi

Bugun qilmang: Chiroyli dizayn, animatsiya, task minigame, inventory UI. Placeholder yetarli. To‘liq UMG — Stage 10 (Day 64+).

Nima uchun erta UI? Interact faqat eshik/light emas — ba’zan ekran ochadi. Bog‘lanishni endi o‘rganasiz; bezak keyin.

? Nima uchun Computer?

Betray Builder’da task, voting, map, chat — ko‘pi UI. Agar Interaction faqat world Actor bilan cheklansa, keyin UI’ni “qayerdan chaqirish” chalkashadi.

Computer = world interactable → screen UI namunasi. Player BPI orqali Computer’ga E; Computer Widget ochadi. Keyin WBP ichini to‘ldirasiz.

🖥 UMG — qisqa kirish

UMG (Unreal Motion Graphics) — Widget Blueprint asosidagi UI tizimi.

  • Widget Blueprint (WBP_) — UI “class”
  • Create Widget — runtime nusxa
  • Add to Viewport — ekranga chiqarish
  • Remove from Parent — yopish / olib tashlash

Designer: Canvas Panel, Text, Button. Graph: OnClicked eventlar. Bugun minimal: 1 Text + 1 Button.

⌨ Input Mode — Game vs UI

Mode Ma’no
Game Only Input o‘yinga (WASD, look). Cursor odatda yashirin.
UI Only Input widget’ga. O‘yin harakati to‘xtashi mumkin.
Game and UI Ikkalasi (pause menu ba’zan).

Computer ochilganda: UI Only + Show Mouse Cursor = true. Yopilganda: Game Only + cursor false.

Node’lar Player Controller da: Set Input Mode UI Only (Widget focus), Set Show Mouse Cursor, Set Input Mode Game Only.

Focus: Set Input Mode UI Only da In Widget to Focus — ochilgan WBP reference. Aks holda tugmalar “o‘lik” bo‘lishi mumkin.

Troubleshooting

Muammo → yechim

Widget ko‘rinmaydi

  • Add to Viewport chaqirilganmi?
  • Create Widget class to‘g‘rimi?
  • ZOrder / visibility

Close ishlamaydi / cursor yo‘q

  • Show Mouse Cursor true?
  • Input Mode UI Only + focus widget?
  • Button Is Enabled, OnClicked ulangan?

Yopilgach o‘yin boshqarilmaydi

  • Set Input Mode Game Only
  • Show Mouse Cursor false

Bir nechta widget qatlam

  • Qayta ochishdan oldin eski Remove

E widget ochiqda ham ishlaydi

  • UI Only ba’zan game input’ni to‘liq kesmaydi — challenge Disable Input
★

Challenge — Disable Input

Widget ochilganda Pawn/Player:

Disable Input (Target = Player Pawn, Player Controller).

Close da: Enable Input.

Instigator Interact’da Player — uni saqlab Close’ga yetkazish qiyinroq (Dispatcher yoki PC orqali Get Pawn). Sodda yo‘l: Computer Interact da Get Player Pawn Disable; Widget Close da Get Player Pawn Enable.

? FAQ

Widget Component (3D) bilan farqi?
Widget Component — dunyoda mesh ustida UI. Viewport — to‘liq ekran. Task odatda Viewport; monitor 3D bo‘lishi mumkin.

Sodda. Alternative: bir marta yaratib Hide/Show. Create+Remove ham OK placeholder uchun.
Common UI / Enhanced Input UI?
Keyinroq. Hozir classic Set Input Mode yetarli.

O‘zingizga savol

Close bosilganda nima qaytarilmasa o‘yin “sinadi”? (Input Mode Game Only + cursor.)

Keyingi kunga

Computer ochilish/yopilish ishonchli bo‘lsin.

Placeholder matnida “Stage 10” eslatmasi — kelajak o‘zingizga.

Qo‘shimcha: Owning Player va local multiplayer

Create Widget da Owning Player — qaysi Player Controller widget’ni “egalik” qiladi. Single player: index 0.

Split-screen da har o‘yinchi o‘z UI’siga ega bo‘lishi kerak — noto‘g‘ri PC bo‘lsa widget boshqa ekranda chiqadi.

Hozir Get Player Controller 0 yetarli.

Qo‘shimcha: Focus va gamepad

UI Only da Widget to Focus — klaviatura/gamepad navigatsiyasi shu widget’dan boshlanadi.

Button uchun Is Focusable. Sichqoncha asosiy bo‘lsa ham focus bering.

ZOrder

Add to Viewport ZOrder — qatlam. HUD 0, modal computer 10. Placeholder da default OK.

UI anti-patternlar

Tick da Create Widget

Har frame yangi UI — crash / lag. Faqat Interact da.

Hard reference levelga WBP instance

Runtime Create — to‘g‘ri yo‘l.

Chuqlashtirish 1

Computer UI ochilganda o‘yinchi e’tibori ekranga o‘tadi. Bu design jihatdan “modal” interaksya: dunyo to‘xtamasa ham, boshqaruv UI ga beriladi.

Input Mode juftligi (UI Only / Game Only) — eng muhim intizom. Bir tomonini unutsangiz, playtest “buzilgan his” beradi: sichqoncha o‘yinda qoladi yoki WASD UI da ishlaydi.

Placeholder matnni ongli ravishda oddiy qoldiring. Vaqtni Stage 10 dizayniga saqlang; hozir zanjir ishonchliligi muhimroq.

BP_Computer mesh faqat nishon — haqiqiy “ish” WBP da. Shu ajratish clean architecture.

  • Create Widget — instance
  • Add to Viewport — ko‘rinish
  • Input Mode — boshqaruv
  • Remove + Game Only — tozalash
