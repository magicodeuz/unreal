KUN 4 / 90 STAGE 1 · FUNDAMENTALS QAYTA ISHLATISH

Events va Functions

Kodni bo‘laklarga ajratish: Custom Event — “signal”; Function — “hisoblab qaytar”.

Bugungi aniq maqsad

OnActivate Custom Event + E tugmasi. GetDoubledValue(Integer) Function. Enhanced Input hali yo‘q — oddiy Keyboard Event.

01 Qachon nima ishlaydi?

BeginPlay — bir marta · Tick — har frame ⚠️ · Input — tugma · Custom — siz chaqirasiz

Tick ni bugun ishlatmang — sekin ishlaydigan o‘yinlarning asosiy sabablaridan biri. Faqat bilib turing: u mavjud.

02 Custom Event vs Function — qachon qaysi?

Custom Event
  • “Nimadir bo‘ldi” deb signal
  • Odatda qiymat qaytarmaydi
  • Ketma-ket amallar (Print, ovoz, effekt)
  • Boshqa joydan Call qilinadi
Function
  • “Hisobla va qaytar”
  • Return value bor
  • Toza, qayta ishlatiladi
  • Masalan: ×2, masofa, tekshiruv

Bugun ikkalasini ham yozasiz: E → OnActivate (event), GetDoubledValue (function).

03 OnActivate oqimi 

Keyboard E (Pressed)
  → Call OnActivate

Custom Event: OnActivate
  → Print String ("Obyekt faollashtirildi")

Nima uchun to‘g‘ridan-to‘g‘ri Print emas? Keyinroq OnActivate ga ovoz, animatsiya, interface qo‘shiladi — E faqat “chaqirish” qoladi.

04 GetDoubledValue(Integer) 

Function: GetDoubledValue
  Input:  Value (Integer)
  Return: Integer

  Return Node ← Value × 2

My Blueprint → Functions → +. Pure qilish ixtiyoriy. Chaqirish: graph da function nomini yozing, input ulang, return dan Print ga.

05 Amaliy qadamlar

1

Custom Event OnActivate

  1. Event Graph → o‘ng tugma → Add Custom Event → OnActivate.
  2. Undan Print String: Obyekt faollashtirildi.
2

E tugmasi

  1. O‘ng tugma → Keyboard → E (Pressed).
  2. Pressed → Call OnActivate.
  3. Compile, Play, E bosing.

Input Actor da ishlamasa — vaqtincha Character/Controller da sinang; maqsad Call oqimi.

3

GetDoubledValue

  1. Functions → + → GetDoubledValue.
  2. Input: Integer (masalan Value).
  3. Outputs → Return Value: Integer.
  4. Ichida: Value × 2 → Return Node.
