Player’da olingan item’larni saqlaydigan haqiqiy Inventory Array tizimini yaratish. S_ItemData Struct + InventoryArray + hajm cheklovi (max 8) + kecha yozilgan AddItemToInventory ni to‘liq ishlatish.

01 Nima uchun bu kun muhim?

Day 30’da biz item’ni “oldik” — lekin u hech qayerga saqlanmadi. Print String chiqdi va yo‘qoldi. Bu demo edi. Bugun esa haqiqiy xotira yaratamiz.

Inventory — o‘yinchining cho‘ntagi. Key eshik ochadi, Battery generatorni ishga tushiradi, Medkit sog‘liqni tiklaydi. Bularning hammasi Inventory’da turishi kerak. Agar bugun to‘g‘ri qilsak, keyingi kunlar (Use Item, Drop, UI) oson kechadi.

Professor eslatmasi

Ko‘p yangilar Inventory’ni “har item uchun alohida Boolean” qilib yozadi: HasKey, HasBattery, HasMedkit… Bu 5 item’da ishlaydi, 20 item’da do‘zaxga aylanadi. Array of Struct — professional yechim. Bir xil kod bilan cheksiz turdagi item’larni boshqarasiz.

02 Nazariya — Struct va Array

Struct nima?

Struct — bir nechta turli tipdagi qiymatlarni bitta “paket”ka birlashtiradigan ma’lumot turi. Oddiy misol: odamning ismi (String), yoshi (Integer), bo‘yi (Float) — bularni alohida saqlash o‘rniga “Person” degan Struct ichiga solib qo‘yasiz.

Bizning holatda S_ItemData — bitta item haqidagi barcha kerakli ma’lumot:

Maydon Tip Vazifasi
ItemID Name Tizim ichida aniqlash (Key, Battery…)
ItemName String O‘yinchiga ko‘rsatiladigan nom
Icon Texture2D Inventory UI uchun rasm

Array nima?

Array — bir xil tipdagi elementlarning tartibli ro‘yxati. InventoryArray — bu S_ItemData larning ro‘yxati. Har safar item olinganda yangi Struct yaratiladi va Array’ning oxiriga qo‘shiladi.

InventoryArray (misol holati)

Key · Eski kalit
[1]
Battery · Batareya
[2]
Medkit · Aptecka
[3] … [7] bo‘sh
Length = 3 / Max = 8

03 S_ItemData Struct yaratish

Struct alohida asset. Uni Blueprint ichida emas, Content Browser’da yaratamiz.

  1. Content Browser → Content/BetrayBuilder/Blueprints/Items/ (yoki Data/)
  2. O‘ng tugma → Blueprints → Structure
  3. Nomini S_ItemData deb qo‘ying (S_ prefiksi — Struct ekanligini bildiradi)
  4. Ochib, quyidagi 3 ta maydonni qo‘shing:
Member Name Type
ItemID Name
ItemName String
Icon Texture2D (Object Reference)

Naming: Struct’lar odatda S_ prefiksi bilan ataladi (S_ItemData, S_Objective, S_PlayerStats…). Bu Content Browser’da tez topishga yordam beradi.

06 Hajm cheklovi — nima uchun 8?

Cheksiz Inventory o‘yin balansini buzadi. O‘yinchi hamma narsani olib yuradi, qaror qabul qilish shart emas. 8 ta slot — yetarli, lekin tanlashga majbur qiladi.

Branch orqali tekshiramiz:

  • Length < 8 → True → Make Struct + Add
  • Length >= 8 → False → Print String: “Inventory to‘la!” va Destroy qilmaymiz (item joyida qoladi)

Muhim: Inventory to‘la bo‘lsa, BP_Item tomonida Destroy Actor chaqirilmasligi kerak. Buning uchun AddItemToInventory Boolean qaytarishi mumkin (true = qo‘shildi, false = to‘la). BP_Item faqat true bo‘lsa Destroy qiladi.

AddItemToInventory ni yangilash

Funksiyani oching va ichini quyidagicha qayta yozing:

// BP_Player → AddItemToInventory
// Inputs: ItemID (Name), ItemName (String), ItemIcon (Texture2D)
// Output (tavsiya): Return Value (Boolean) — muvaffaqiyat

1. Length (InventoryArray) → hozirgi son
2. Branch:
   Condition: Length < 8

   --- TRUE (joy bor) ---
   3. Make S_ItemData
      - ItemID   ← input ItemID
      - ItemName ← input ItemName
      - Icon     ← input ItemIcon
   4. Add (InventoryArray)
      - Target Array: InventoryArray
      - New Item: Make S_ItemData natijasi
   5. Print String: "Olindi: " + ItemName + " | " + Length+1 + "/8"
   6. Return true

   --- FALSE (to'la) ---
   7. Print String: "Inventory to'la! (8/8)"  (qizil rang)
   8. Return false
4

BP_Item → Interact ni moslashtirish

Agar AddItemToInventory Boolean qaytarsa — Destroy faqat True bo‘lganda chaqiriladi: 

// BP_Item → Interact
1. Cast Instigator to BP_Player
2. Cast Succeeded:
   - AddItemToInventory (ItemID, ItemName, ItemIcon)
   - Return Value pinidan Branch
     - True  → Destroy Actor (self)
     - False → hech narsa (item joyida qoladi, o'yinchi ko'radi)
5

09 Keng tarqalgan xatolar

1. “S_ItemData type topilmayapti”

Struct’ni saqlaganingizga ishonch hosil qiling. BP_Player’ni yopib qayta oching. Type qidiruvida “ItemData” deb yozing.

2. Array Length doim 0 chiqadi

Add node to‘g‘ri ulanganini tekshiring. Target Array piniga InventoryArray variable’ini ulang. Make S_ItemData natijasini New Item piniga ulang.

3. 8 tadan keyin ham qo‘shilaveradi

Branch Condition’ini tekshiring: Length < 8 bo‘lishi kerak (≤ 7). Agar ≤ 8 deb yozgan bo‘lsangiz — 9-chi ham o‘tadi.

4. Inventory to‘la bo‘lsa ham item yo‘qoladi

BP_Item da Destroy Actor ni AddItemToInventory ning Return Value’siga bog‘lang. Faqat true qaytsa Destroy qiling.

5. Make S_ItemData pinlari mos kelmayapti

Struct maydon nomlari va funksiya input nomlari bir xil bo‘lishi shart emas, lekin tip mos kelishi shart. Name → Name, String → String, Texture2D → Texture2D.

Bu uchun GetInteractionText ichida Player’ni topib, InventoryArray Length’ini tekshirish kerak. Bir oz murakkabroq, lekin juda foydali UX yaxshilanishi.

★ Professor izohi

Bugun siz ma’lumot strukturasi bilan ishladingiz. Struct + Array — bu dasturlashning eng asosiy qurilish bloklaridan biri. Unreal’da ham, C++ da ham, Python’da ham, veb’da ham shu g‘oya ishlatiladi.

Yana bir muhim dars: cheklovlar dizaynning bir qismi. 8 ta slot — bu texnik cheklov emas, o‘yin dizayni. O‘yinchi “nima olib yurishim kerak?” deb o‘ylashi kerak. Cheksiz cho‘ntak — zerikarli cho‘ntak.

Ertaga (Day 32) biz ma’lumotni yanada professional qilamiz — Data Table. Lekin bugungi Array allaqachon ishlaydigan, kengaytiriladigan tizim.

→ Keyingi kun — Day 32: Item Data (Data Table)

Ertaga item ma’lumotlarini Data Table’ga ko‘chiramiz. BP_Item faqat ItemID saqlaydi, qolgani (Name, Icon, Description) jadvaldan o‘qiladi. Bu — data-driven design. Bitta jadvalni tahrirlab, butun o‘yin item’larini boshqarasiz.
