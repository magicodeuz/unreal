Stage 3 yakuni · MILESTONE 3 · Integration Test

Universal Interaction Test

Yangi feature yo‘q. Faqat: Door, Button→Door, LightSwitch, Computer — bitta Trace + bitta BPI orqali ishlashini isbotlash.

🎯 Kun maqsadi

  • → MAP_InteractionTest — bitta xona, 4 tur
  • → Har birini alohida + ketma-ket sinash
  • → Trace masofasi (300) tashqarida E ishlamasin
  • → CanInteract / matn (Print yoki UI) tekshiruv
  • → Topilgan bug’larni shu kun tuzatish
  • → Milestone 3 yashil

Yangi obyekt turi qo‘shmang (faqat challenge’da ixtiyoriy 5-chi). Integration = mavjudlarni birga sinash.

Nima uchun muhim? Keyingi 70 kunda generator, sabotage, voting — hammasi shu BPI ga tushadi. Bugun ishonch = keyin tezlik.

? Integration testing nima?

Har bir kun alohida “unit” ishlagan. Bugun: birga ishlaydimi? Bitta Player graph, bitta Trace, bitta interface — to‘rt xil natija.

Real loyihada yangi feature qo‘shishdan oldin regression test: eski eshik hali ochiladimi?

Xato topsangiz — Stage 4 ga olib o‘tmang. Tuzating, keyin milestone.

🏗 Arxitektura — nima sinayapmiz 

Player (bitta zanjir)
  Line Trace (Visibility, ~300)
  → CurrentFocusedActor
  → DoesImplement BPI_Interact?
  → CanInteract Message?
  → GetInteractionText (Print / keyin UI)
  → E → Interact Message

Implementors (turli mantiq, bir xil shartnoma):
  BP_Door          Timeline rotation
  BP_Button        Message → TargetDoor
  BP_LightSwitch   Point Light Visibility
  BP_Computer      Create Widget + Input Mode

Agar bitta Cast To BP_Door Player’da qolgan bo‘lsa — bugun topib olib tashlang.

📋 4 obyekt — kutilgan xulq

Actor E natijasi Maxsus
Door Ochilish/yopilish Anim paytida CanInteract false
Button Bog‘langan Door toggle TargetDoor valid
LightSwitch Yorug‘lik on/off Sezilarli farq
Computer Widget + cursor Close → Game input

4 obyektni joylash

Button → Door wiring

Taxminiy vaqt: 5 daqiqa

Bo‘sh qolsa Button testi fail.

5

Test matrisa (asosiydir)

Har katakni o‘zingiz belgilang

Play → har bir qator:

Matn: UI prompt bo‘lmasa Player’da focus o‘zgarganda Print GetInteractionText — to‘g‘ri string kelishini tekshiring.

6

Masofa testi (300 unit)

Taxminiy vaqt: 10–15 daqiqa

Trace distance (Day 15) odatda ~300. Obyektdan uzoqlashib E:

  • Focus yo‘qolishi kerak (debug line qizil / Print null)
  • E hech narsa qilmasligi kerak

Yaqinlashib qayta — ishlashi kerak. Bu “cheksiz interact” bug’ini ushlaydi.

7

CanInteract va matn

Door animating: CanInteract false → E o‘tkazib yuboriladi.

Button TargetDoor bo‘sh: CanInteract false (agar shunday yozgan bo‘lsangiz).

Matn: ochiq eshik “yopish”, o‘chiq chiroq “yoqish” — holatga bog‘liq.

8

Xatolarni tuzatish protokoli

  1. Qaysi obyekt? (faqat Computer?) → shu BP
  2. Hammasi? → Player Trace / BPI Message
  3. Focus bormi? Collision Visibility?
  4. DoesImplement true?
  5. CanInteract true?
  6. Interact ichida null / Is Valid?

Bir xatoni tuzatib, butun matrisani qayta yugurting (regression).

★

Challenge — 5-obyekt (chelak)

Yangi BP (masalan BP_Bucket): mesh + BPI.

Interact: Print “Chelak bosildi” yoki kichik scale pulse.

Player’ga hech narsa qo‘shmang. Agar E ishlasa — system universal.

Bu “scalable” isboti. Keyin o‘chirib qo‘yishingiz mumkin.
