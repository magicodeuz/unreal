Stage 3 · Kun 17 · Birinchi haqiqiy Interactable

Door

Trace + BPI endi gameplay beradi: E → eshik silliq ochiladi / yopiladi. Timeline, Lerp Rotator, holat matni.

🎯 Kun maqsadi

  • → BP_Door — Static Mesh + interaction collision
  • → BPI_Interact to‘liq implement (Interact, Text, CanInteract)
  • → Timeline 0.5 s: Yaw 0° ↔ 90° silliq
  • → bIsOpen / animatsiya bandligi
  • → GetInteractionText: “Ochish” / “Yopish”
  • → Player kodiga hech narsa qo‘shilmaydi — faqat Door

Bugun qilmang: Kalit / qulf (Day 33 Item), Audio asset (Print bilan belgilang), sliding door, double door. Bitta aylanuvchi panel yetarli.

? Nima uchun aynan Door?

Eshik — eng tushunarli interactable: ko‘rinadi, eshitiladi (keyin), map’ni bo‘ladi. Betray Builder’da xonalar, vent yo‘llari, meeting xonasi — hammasi eshik bilan bog‘liq.

Texnik jihatdan: Timeline + Rotation keyin chest qopqog‘i, lever, hatch uchun ham ishlatiladi. Bir marta o‘rganasiz — qayta ishlatasiz.

Muhim dars: Player’da yangi Cast yozilmadi. BP_Door faqat BPI_Interact implement qildi — Kun 16 va’dasi ishladi.

⏱ Timeline — nima va nima uchun?

Timeline — vaqt bo‘yicha float (yoki vector) qiymat chiqaradigan node. Length = 0.5 s bo‘lsa, Play bosilganda 0.5 soniya ichida track 0→1 (yoki sizning egri) yuradi.

Har Update pinida joriy Alpha keladi → Lerp(ClosedRot, OpenRot, Alpha) → Set Actor Rotation. Natija: silliq ochilish.

Nima uchun birdan Set Rotation emas? 0° dan 90° ga bir frame’da — “teleport”. O‘yinchi ko‘zi charchaydi, collision g‘alati. Timeline = vaqt.

Pin Ma’no
Play0 dan Length gacha
Play from StartQayta 0 dan
ReverseOrqaga (yopish)
UpdateHar frame track qiymati
FinishedAnimatsiya tugadi
New Track (Float)0→1 egri

Alternativ: Tick + FInterp To Rotation. Timeline ko‘pincha aniqroq “0.5 soniya ochil” uchun qulay.

⚓ Pivot — eshik qayerdan aylanadi?

Actor Rotation o‘z pivot / origin atrofida aylanadi. Agar mesh markazda bo‘lsa — eshik “o‘rtadan” ochiladi (g‘alati). Kerak: menteşe chetda.

Yechimlar:

  • Mesh’ni DCC da pivot’ni menteşega ko‘chirish (eng toza)
  • Scene component “Hinge” root — mesh offset child; rotation Hinge’da
  • Oddiy cube bilan: cube’ni root’dan siljitib, vizual menteşe root’da

Bugun: Engine default Cube yoki Door mesh. Agar markazdan aylansa — Static Mesh component’ni X yoki Y bo‘yicha siljiting (Relative Location), Root (DefaultSceneRoot) menteşe bo‘lib qolsin. Rotation Root yoki butun Actor’da.

Event Interact (BPI)
  │
  ├─ Branch (bIsAnimating?) → True: return
  ├─ Branch (bIsOpen?)
  │     False (yopiq → ochish):
  │       Set bIsAnimating = true
  │       Timeline Play (0→1)
  │     True (ochiq → yopish):
  │       Set bIsAnimating = true
  │       Timeline Reverse (1→0)
  │
Timeline Update (Alpha 0..1)
  │
  ├─ Lerp (ClosedRotation, OpenRotation, Alpha)
  └─ Set Actor Rotation (yoki Set Relative Rotation)

Timeline Finished
  │
  ├─ Set bIsOpen = !bIsOpen   (yoki Play/Reverse ga qarab)
  └─ Set bIsAnimating = false

GetInteractionText:
  Return bIsOpen ? "Eshikni yopish [E]" : "Eshikni ochish [E]"

CanInteract:
  Return !bIsAnimating   (anim paytida qayta bosish yo‘q)
  // keyinroq: && !bIsLocked

Timeline sozlash

5.1 Add Timeline

My Blueprint → Add → Timeline → nom: TL_Door

Ochilganda: Length = 0.5 (soniya). Use Last Keyframe? default.

Event Interact

Taxminiy vaqt: 20 daqiqa

6.1 Zanjir 
Event Interact
  → Branch bIsAnimating → True: return
  → Branch bIsOpen
       False:
         Set bIsAnimating true
         TL_Door Play
         (challenge) Print "Door opening..."
       True:
         Set bIsAnimating true

✓ Yakuniy checklist

⏱ Timeline — qo‘shimcha detallar

Length tanlash

0.3 s — o‘yin / arcade. 0.5 s — muvozanat. 1.0 s — og‘ir eshik his. Betray Builder uchun 0.4–0.6 oralig‘i yaxshi.

Key interpolation

Linear: doimiy tezlik. Auto/Cubic: boshida sekin, o‘rtada tez. Eshik uchun biroz Ease Out “yopilib qolish” hissini beradi.

Play from Start vs Play

Play from Start har doim 0 dan. Agar animatsiya o‘rtasida to‘xtatib qayta ochish kerak bo‘lsa — murakkabroq. Oddiy toggle uchun: yopiqdan Play from Start, ochiqdan Reverse.

Finished ishonchliligi

Timeline to‘liq tugaganda Finished chiqadi. Agar Stop chaqirsangiz — Finished kelmasligi mumkin; bIsAnimating ni Stop da ham tozalang.

📐 Rotatsiya — qisqa matematika

Unreal Rotator: Pitch (Y), Yaw (Z), Roll (X) — gradus.

Eshik odatda Yaw (vertikal o‘q atrofida). Lerp Rotator ichida engine qisqa yo‘lni tanlashi mumkin; 0→90 xavfsiz. 0→270 o‘rniga −90 afzal.

BeginPlay da Closed = GetActorRotation(); Open = Closed + MakeRotator(0, 0, OpenAngle). Bu levelda eshik allaqachon 45° bo‘lsa ham “yopiq” holatni saqlaydi.
