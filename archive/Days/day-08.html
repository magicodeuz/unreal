Stage 2 · Kun 8 / 14

Character

O‘zingizning BP_Player Character Blueprint’ingizni noldan yaratasiz va Capsule, Mesh, Movement, Camera tarkibini tushunasiz.

🎯 Kun maqsadi

Bugun siz:

  • → BP_Player Character Blueprint yaratasiz
  • → Capsule o‘lchamini standart qoldirasiz (42 / 96)
  • → Mannequin (yoki boshqa) Skeletal Mesh biriktirasiz
  • → SpringArm + Camera qo‘shasiz (asosiy joylashuv)
  • → BP_GameMode da Default Pawn = BP_Player
  • → World Settings orqali Game Mode’ni faollashtirasiz

Bugun yozmang: WASD / Sprint / Crouch mantiq (Kun 9–11), kamera sozlamalarini chuqurlashtirish (Kun 12). Faqat “tana” va spawn.

📖 Asosiy tushunchalar

Character

Pawn’ning maxsus turi. Ichida tayyor Character Movement Component bor — yurish, sakrash, gravitatsiya, yerdan turish avtomatik. Oddiy Pawn’da bularni o‘zingiz yozishingiz kerak bo‘lardi.

Capsule Component

Root collision — silindr + ustki/pastki yarim shar. Murakkab Mesh o‘rniga sodda shakl: fizika va “eshikdan o‘tish” tez hisoblanadi. Standart: Radius 42, Half Height 96 (to‘liq balandlik ~192).

Skeletal Mesh

Ko‘rinadigan 3D model (suyaklar bilan). Mannequin / Quinn — UE template’dagi odam modeli. Collision asosan Capsule’da; Mesh ko‘pincha “No Collision” yoki query only.

Character Movement Component

Max Walk Speed, Jump Z Velocity, Gravity Scale va h.k. Character yaratilganda avtomatik qo‘shiladi. Kun 9–11 da sozlaymiz.

Spring Arm + Camera

Spring Arm (Boom) — kamera masofasi va to‘siqlardan “siqilish”. Camera — o‘yinchi ko‘zi. Third person uchun Mesh orqasida. Chuqur sozlash — Kun 12.

Game Mode

“Bu o‘yinda qaysi Pawn spawn bo‘ladi, qaysi HUD, qaysi Player Controller?” — qoidalar. Default Pawn Class = BP_Player qilsak, Play da sizning character’ingiz chiqadi.

🌳 Maqsad hierarchy 

BP_Player (Character)
├── CapsuleComponent          ← Root (collision)
│     ├── Mesh (SkeletalMesh) ← Mannequin
│     └── SpringArmComponent
│           └── CameraComponent
└── CharacterMovement         ← avtomatik (Components ro‘yxatida)

Mesh va SpringArm odatda Capsule’ning Child’i. Movement alohida “non-scene” component.

⚙️ Oldindan talab

  • ✓ Stage 1 yakunlangan (yoki kamida project + papkalar bor)
  • ✓ Third Person yoki First Person starter content (Mannequin mesh uchun) — yo‘q bo‘lsa Engine Content / boshqa skeletal mesh

Mannequin: Content Browser → Settings (View Options) → Show Engine Content / Show Plugin Content. Qidiruv: SKM_Manny yoki SK_Mannequin / Quinn.

BP_Player yaratish

1.1 Papka

1.2 Blueprint Class → Character

O‘ng sichqoncha → Blueprint Class

Nom: BP_Player

Ochilganda Components’da allaqachon Capsule + CharacterMovement ko‘rinishi kerak.

Tekshirish: Content/BetrayBuilder/Characters/BP_Player

2

Capsule o‘lchami

Taxminiy vaqt: 5 daqiqa

2.1 Standart qiymatlar

Components → CapsuleComponent tanlang → Details:

  • Capsule Radius: 42.0
  • Capsule Half Height: 96.0

Default odatda shu. O‘zgartirmang — Door, Interaction masofasi, crouch keyinroq shu asosga bog‘lanadi.

Nima uchun 42 / 96? UE odatiy “odam” o‘lchami. Eshiklar va corridor’lar shu capsule o‘tadigan qilib blockout qilinadi (Stage 4).

3

Skeletal Mesh biriktirish

Taxminiy vaqt: 15–20 daqiqa

3.1 Mesh component

Components’da Mesh (SkeletalMeshComponent) allaqachon bo‘lishi mumkin — Character parent’dan keladi. Yo‘q bo‘lsa: + Add → Skeletal Mesh.

Mesh tanlang → Details → Skeletal Mesh → Mannequin / SKM_Manny / SKM_Quinn.

3.2 Transform sozlash

Mesh odatda Capsule markazida “suzib” turadi yoki noto‘g‘ri yo‘nalgan. Tipik sozlash (template’ga qarab farq qiladi):

  • Location Z: manfiy qiymat (oyoqlar capsule pastiga tushsin) — masalan -90 yoki -96
  • Rotation Z: -90 (ko‘pincha mesh “yonboshi” turadi)

Viewport’da oyoqlar capsule pastiga, bosh yuqorisiga yaqin tursin. Show → Collision bilan solishtiring.

Anim Blueprint: Hozircha Anim Class bo‘sh qolishi mumkin — T-pose / default pose. Kun 13 atrofida animatsiya. Mesh ko‘rinsa yetarli.

4

SpringArm + Camera

Taxminiy vaqt: 10–15 daqiqa

4.1 Component qo‘shish

Capsule (yoki Root) tanlang → + Add → Spring Arm

SpringArm tanlang → + Add → Camera (Camera SpringArm’ning Child’i bo‘lsin).

4.2 Minimal sozlash

SpringArm Details (taxminiy boshlang‘ich):

  • Target Arm Length: 300–400
  • Socket Offset / Location: biroz yuqoriga (masalan Z 40–60)
  • Use Pawn Control Rotation: ✓ (kamera controller rotation’ga ergashsin)

Camera: default yetarli. Chuqur (lag, collision test) — Kun 12.

Compile + Save BP_Player.

5

BP_GameMode

Taxminiy vaqt: 10 daqiqa

5.1 Yaratish

Content/BetrayBuilder/Systems/ papkasini yarating (yo‘q bo‘lsa).

Blueprint Class → Parent: Game Mode Base (yoki GameMode)

Nom: BP_GameMode

5.2 Default Pawn Class

BP_GameMode ochiq → Class Defaults / Details:

Default Pawn Class → BP_Player

Compile + Save.

Boshqa maydonlar: Player Controller, HUD hozircha default. Keyinroq BP_PlayerController, WBP_HUD qo‘yiladi.

6

World Settings

Taxminiy vaqt: 5 daqiqa

6.1 Level uchun Game Mode Override

Asosiy Level ochiq bo‘lsin.

Toolbar / Window → World Settings (yo‘q bo‘lsa Window → World Settings).

Game Mode bo‘limi → GameMode Override → BP_GameMode

Level’ni saqlang (Ctrl+S).

Project default: Edit → Project Settings → Maps & Modes → Default Modes → Default GameMode ham BP_GameMode qilishingiz mumkin — barcha yangi level’lar uchun. Hozircha World Settings yetarli.

7

Test qilish

Taxminiy vaqt: 5 daqiqa

Play
  1. Play (Selected Viewport yoki New Editor Window).
  2. BP_Player spawn bo‘lishi kerak (Player Start bor level’da).
  3. Gravitatsiya: yerga tushishi / turishi kerak.
  4. Hozircha WASD ishlamasligi normal — input ertaga.

Muvaffaqiyat: BP_Player yaratildi; BP_GameMode orqali default pawn.

Eski ThirdPerson character chiqsa: World Settings GameMode Override tekshiring; Project Settings Default GameMode; Level’da eski Player Start / possessed pawn.

Capsule vs Mesh

Keyin 42 / 96 ga qaytaring. Shu sabab standart o‘lchamni saqlaymiz.
