Stage 2 · Kun 13 / 14

Player State

Health, Stamina, IsSprinting, IsCrouching — bitta joyda. Sprint endi cheksiz emas: stamina tugasa, yugurish to‘xtaydi.

🎯 Kun maqsadi

Kun oxirida BP_Player’da:

  • → Health / MaxHealth (hozircha faqat ma’lumot)
  • → Stamina / MaxStamina + kamayish/tiklanish
  • → Sprint paytida stamina DeltaTime ga qarab kamayadi
  • → Sprint yo‘qida (yoki sekin) stamina tiklanadi, 0…Max orasida Clamp
  • → Stamina ≤ 0 → majburiy sprint to‘xtashi (speed 300, IsSprinting false)
  • → Yangi sprint faqat stamina > 0 (yoki minimal threshold) bo‘lsa
  • → Mavjud IsSprinting / IsCrouching shu “state to‘plami”ga mos tartibda

Bugun qilmang: Damage / heal gameplay, UI progress bar (Kun ~65), replication (Multiplayer stage). Health faqat “joy ajratilgan” variable.

? Nima uchun / keyingi bosqichlarga bog‘liqligi

Hozircha hamma narsa BP_Player ichida. Bu ongli tanlov: Stage 2 da bitta Character, bitta o‘yinchi, multiplayer yo‘q.

Keyinroq (Multiplayer / Betrayal):

  • PlayerState (UE class) — ball, role, ba’zan health — serverda replicate
  • Yoki alohida ASC / attribute (murakkabroq)
  • Hozirgi variable nomlari va ma’nolari o‘sha tizimga ko‘chirishni osonlashtiradi

Stamina nima uchun kerak? Cheksiz sprint map balance’ni buzadi: doimo eng tez o‘yinchi, stalk / qochish ma’nosiz. Kichik resurs — qaror majburiyati.

Health bugun “bo‘sh joy”: saboteur damage, fall damage, gas — keyin keladi. Variable bo‘lmasa, keyin har joyga chigal qo‘shasiz.

📖 Asosiy tushunchalar

Delta Time

Bir freymdan ikkinchisiga o‘tgan vaqt (soniyada). Stamina o‘zgarishi: Stamina -= Rate * DeltaSeconds. Faqat “har tick −1” qilsangiz, FPS past bo‘lsa sekin, yuqori bo‘lsa tez kamayadi — noto‘g‘ri. Har doim DeltaTime.

Clamp (Float)

Qiymatni Min va Max orasiga “qisib” qo‘yadi. Stamina hech qachon 0 dan past yoki MaxStamina dan oshmasin.

Event Tick vs Timer

Tick: har freym — silliq stamina, oddiy yozish. Kam cost (bir nechta float). Timer: masalan har 0.1 s — kamroq chaqiruv, lekin sekinroq yangilanish. Bugun Tick yetarli va o‘rganish uchun qulay.

Instance Editable + Blueprint Read Only

Details’da level designer ko‘radi (Editable), lekin boshqa Blueprint’dan Set qilish cheklanishi mumkin (Read Only) — “tashqi kod to‘g‘ridan-to‘g‘ri buzmasin, funksiya orqali o‘zgarsin”. Hozir tartib uchun: asosiy state’larni kategoriyaga solib, keraklilarini Editable qiling.

Force stop sprint

Shift hali bosilib turishi mumkin, lekin stamina 0. IsSprinting false + Max Walk Speed 300. Aks holda o‘yinchi “ghost sprint” da qoladi. Shift Completed kelganda ham xavfsiz: allaqachon to‘xtagan bo‘lsa, qayta 300 yozish zararsiz.

1

Variable’lar ro‘yxati — qo‘shish

Taxminiy vaqt: 15 daqiqa

1.1 Yangi float’lar

BP_Player → My Blueprint → Variables. Quyidagilarni qo‘shing (mavjud IsSprinting / IsCrouching’ni saqlang):

Nom Tip Default Category (ixtiyoriy)
Health Float 100 State|Resources
MaxHealth Float 100 State|Resources
Stamina Float 100 State|Resources
MaxStamina Float 100 State|Resources
StaminaDecreaseRate Float 25 State|Tuning
StaminaRegenRate Float 15 State|Tuning
MinStaminaToSprint Float 5 State|Tuning

25 / sek → to‘liq 100 stamina ~4 soniyada tugaydi. 15 regen → ~6.7 s to‘liq tiklanish. Keyin balance qilasiz.

Ixtiyoriy: WalkSpeed = 300, SprintSpeed = 600 — magic number o‘rniga.

Compile.

2

Instance Editable va tartib

Taxminiy vaqt: 10 daqiqa

2.1 Details sozlamalari

Har bir asosiy state variable uchun (tanlang → Details):

  • Instance Editable — levelda/PIE da ko‘rish va sinash uchun (ayniqsa Rate’lar)
  • Blueprint Read Only — ixtiyoriy; “faqat shu BP ichida Set” siyosati uchun
  • Category — State|Resources, State|Movement, State|Tuning
  • Tooltip — qisqa izoh (masalan “Units per second while sprinting”)

Nima uchun? 3 oy keyin “stamina qayerda?” deb qidirmaslik. Multiplayer’da replicate qilinadigan maydonlarni ham shu yerdan tanlaysiz.

3

Rate qiymatlarini his qilish

O‘qib chiqing — keyin kod

DecreaseRate = 25 → 100 / 25 = 4 soniya to‘liq sprint. Map kichik bo‘lsa 4 s yetarli; katta bo‘lsa Rate’ni 15–20 ga tushiring.

RegenRate = 15 → to‘liq tiklanish ~6.7 s. Regen sprint’dan sekinroq bo‘lishi odatiy (yoki teng).

MinStaminaToSprint = 5 → 0 dan darhol qayta sprint yoqilmasin; biroz “nafas olish” majburiy.

Bu raqamlar final emas — playtest (Kun 14) da o‘zgartirasiz. Muhimi: formula DeltaTime bilan to‘g‘ri.

4

Event Tick — stamina yangilash

Taxminiy vaqt: 25–35 daqiqa

4.1 Tick yoqilganmi?

Class Defaults → Actor Tick → Start with Tick Enabled ✓

Event Graph’da Event Tick (Delta Seconds pin).

Agar Kun 11 kamera interp ham Tick’da bo‘lsa — bir xil Tick ichida ketma-ket yozing (avval stamina, keyin kamera yoki aksincha).

4.2 Sprint true tarmog‘i
  1. Branch: IsSprinting
  2. True: Stamina − (StaminaDecreaseRate × Delta Seconds)
  3. Natijani Clamp (Min 0, Max MaxStamina) → Set Stamina

Node’lar: Float − Float, Float * Float, Clamp Float.

4.3 Sprint false — regen

False tarmoq: Stamina + (RegenRate × Delta) → Clamp → Set Stamina.

Ixtiyoriy qoida: Faqat yerdа (Is Moving / not falling) regen. Hozircha oddiy: sprint yo‘q = regen. Keyinroq “harakatlanmasa tezroq regen” qo‘shish mumkin.

5

Stamina ≤ 0 → majburiy to‘xtatish

Taxminiy vaqt: 15 daqiqa

5.1 Tick ichida tekshiruv

Stamina kamaytirib Clamp qilgandan keyin:

Branch (Stamina ≤ 0) AND (IsSprinting)
  True →
    Set Max Walk Speed (WalkSpeed / 300)
    Set IsSprinting = false

Yoki alohida Custom Event ForceStopSprint — Kun 4 dagi odat: bir joyda yig‘ib, Tick va boshqa joylardan chaqirish.

5.2 Nima uchun Custom Event yaxshi?

ForceStopSprint ichida:

  • Max Walk Speed = WalkSpeed
  • IsSprinting = false
  • (Challenge Kun 12) Arm Length qaytarish
  • Keyinroq: sprint VFX o‘chirish, sound stop

Bitta o‘zgarish — bitta event. Tick faqat “Stamina 0 mi?” deb chaqiradi.

6

Sprint Started — stamina eshigi

Taxminiy vaqt: 15 daqiqa

6.1 Kun 10 mantiqini yangilash

IA_Sprint Started zanjiri endi:

Started
  → Branch IsCrouching?  → True: return
  → Branch (Stamina > MinStaminaToSprint)?
       True:
         Set Max Walk Speed = SprintSpeed (600)
         Set IsSprinting = true
       False:
         (ixtiyoriy) Print "Not enough stamina"

Completed o‘zgarishi mumkin: ForceStopSprint chaqirish (yoki speed 300 + IsSprinting false) — Shift qo‘yilganda har doim to‘xtash.

Edge case: Stamina 0 da Shift bosib tursa, regen boshlanadi (IsSprinting false). MinStaminaToSprint ga yetganda avtomatik qayta sprint yoqilmasin — faqat Shift’ni qayta bosganda (Started). Bu hold-to-sprint uchun tabiiy.

7

Clamp, BeginPlay, edge cases

Taxminiy vaqt: 10 daqiqa

7.1 BeginPlay
  • Stamina = MaxStamina

  • IsSprinting = false (xavfsizlik)

Levelda Instance Editable orqali Stamina’ni 50 qilib test qilishingiz mumkin — BeginPlay qayta to‘ldirsa, test uchun BeginPlay’da overwrite’ni vaqtincha o‘chiring.

8

Test va troubleshooting

Taxminiy vaqt: 15–20 daqiqa

Qanday sinash
  1. Shift + WASD — ~4 s yuguring; tezlik birdan 300 ga tushsin.
  2. Shift hali bosiliq bo‘lsa ham — oddiy yurish (force stop).
  3. Shift ni qo‘ying, kuting — stamina o‘ssin; qayta Shift — yana sprint (agar yetarli stamina).
  4. Crouch + Shift — sprint yoqilmasin (oldingi qoida saqlansin).
Muammo → yechim

Stamina umuman kamaymaydi

  • IsSprinting haqiqatan true bo‘lyaptimi? (Print)
  • Tick enabled?
  • DecreaseRate × Delta ulanganmi (faqat −1 emas)?

Juda tez / juda sekin tugaydi

  • Rate’ni o‘zgartiring; FPS bilan bog‘liq emasligi uchun DeltaTime majburiy

0 da sprint davom etadi

  • ForceStopSprint chaqirilyaptimi?
  • Max Walk Speed qayta 600 ga boshqa joydan yozilmayaptimi?

Stamina 100 dan oshib ketadi

  • Clamp Max = MaxStamina

Regen sprint paytida ham ishlaydi

  • Branch IsSprinting tarmoqlari aralashib ketmaganligini tekshiring
★

Challenge — debug Print

Har Tick (yoki har 0.25 s Timer) Stamina ni Print String qiling (To String + “Stamina: ”).

Kamayish/tiklanish silliqligini ko‘ring. Keyin majburiy o‘chiring — ekran spam final o‘yinda qolmasin.

Yaxshiroq alternativ: Draw Debug String yoki faqat Stamina 10 dan pastga tushganda Print.

★ Bonus g‘oyalar (ixtiyoriy)

B1 Regen delay

Sprint to‘xtagach 0.5–1 s kutib regen boshlash (oxirgi sprint vaqti variable + Tick da solishtirish).

B2 Crouch ham stamina yeydi

Juda sekin (masalan 5/s) — “yashirinish ham charchatadi”. Balance uchun ehtiyot.

B3 GetStaminaPercent function

Return Stamina / MaxStamina — keyin UI Progress Bar uchun tayyor (Kun 65).

B4 Health hali “o‘lik” kod emas

GetHealthPercent xuddi shu. Damage event’ni stub qilib qo‘yish mumkin (Print “Damage received”) — chaqirmasangiz ham bo‘ladi.
