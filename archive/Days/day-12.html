Stage 2 · Kun 12 / 14

Camera

Sichqoncha bilan qarash (IA_Look), SpringArm masofasi, lag va pitch chegarasi — to‘liq third-person kamera.

🎯 Kun maqsadi

Kun oxirida:

  • → Sichqoncha harakati kamerani / qarashni aylantiradi
  • → Yurish kamera qarab turgan tomonga bog‘liq (Kun 9 dagi Control Rotation endi “jonli”)
  • → SpringArm: Target Arm Length ≈ 300, Collision Test, ixtiyoriy Camera Lag
  • → Pitch yuqori/past chegaralangan — bosh aylanib ketmaydi
  • → Sensitivity sozlanadigan (variable)

Bugun qilmang: First-person kamera, Camera Shake (Keyinchalik VFX/Feedback), murakkab lock-on. Faqat classic third-person look.

? Nima uchun bu kun muhim?

Kun 9 da yurish Control Rotation ga bog‘langan edi, lekin sichqoncha hali rotation’ni o‘zgartirmagan bo‘lishi mumkin — o‘yinchi “bir tomonga qarab” qoladi yoki template default ishlaydi.

Betray Builder map’da o‘ynash, eshiklarni ko‘rish, boshqa o‘yinchilarni kuzatish — hammasi kameraga bog‘liq. SpringArm devorga tiqilganda kamerani yaqinlashtiradi (o‘yinchi mesh ichiga “kirib ketmasin”). Pitch limit siz uchib ketish yoki 360° aylanib ko‘ngil aynishini oldini oladi.

Bu kun Stage 2 ning “ko‘z” qismi: yurish + sprint + crouch + endi qarash = to‘liq harakatlanuvchi third-person o‘yinchi.

📖 Asosiy tushunchalar

Spring Arm Component

Character va Camera orasidagi “boom”. Target Arm Length — ideal masofa (masalan 300). Do Collision Test yoqilsa, devor/shift orasida kamera avtomatik yaqinlashadi. Camera Lag — kamera biroz “orqada qolib” ergashadi (silliq, cinematic).

Use Pawn Control Rotation

SpringArm (yoki Camera) Player Controller’ning Control Rotation’iga bog‘lansin. Sichqoncha Control Rotation’ni o‘zgartiradi → arm + kamera aylanadi. Mesh odatda Use Control Rotation = false (yoki faqat Yaw) — character tanasi har doim kamera bilan 1:1 aylanmasligi mumkin; ko‘pincha Movement “orient rotation to movement” bilan tanani yurish tomonga buradi.

Add Controller Yaw / Pitch Input

Controller rotation’ga qo‘shimcha burchak. Yaw = gorizontal (chap/o‘ng qarash), Pitch = vertikal (yuqori/past). Mouse Y odatda teskari kerak bo‘ladi (Value.Y * −1) — “sichqoncha yuqoriga = tepaga qarash” yoki aksincha (invert option).

View Pitch Min / Max

Player Controller (yoki Pawn) da pitch chegarasi. Masalan −60° … +60° yoki −70 … 70. Cheksiz pitch = kamera aylanib “ag‘dariladi”.

IA_Look Axis2D

Mouse X/Y delta. Enhanced Input da Mouse XY 2D axis sifatida map qilinadi. Sensitivity ba’zan IMC modifier’da, ba’zan Blueprint’da multiply.

↗ Mantiq sxemasi 

IA_Look (Triggered) → Action Value (Vector2D)
    │
    ├─ Break Vector2D → X, Y
    │
    ├─ Add Controller Yaw Input   (X * MouseSensitivity)
    └─ Add Controller Pitch Input (Y * MouseSensitivity * -1)

SpringArm (Defaults)
  Target Arm Length = 300
  Use Pawn Control Rotation = true
  Do Collision Test = true
  Camera Lag (ixtiyoriy) Speed ≈ 10

PlayerController / Pawn
  View Pitch Min / Max = chegara

1

IA_Look yaratish va IMC’ga bog‘lash

Taxminiy vaqt: 15–20 daqiqa

1.1 Input Action

Input papkasi → Input Action → IA_Look

Value Type: Axis2D (Vector2D)

Save.

1.2 IMC — Mouse XY

IMC_BetrayBuilder → yangi mapping:

  • Action: IA_Look
  • Key: Mouse XY 2D-Axis (yoki Mouse X va Mouse Y alohida, Swizzle bilan Axis2D)

UE5 da ko‘pincha bitta “Mouse XY 2D-Axis” mapping yetarli. Third Person template IMC’sida Look qanday yozilganini ochib nusxa ko‘rishingiz mumkin.

Modifiers: Ba’zan Negate Y shu yerda qo‘yiladi (invert look). Yoki Blueprint’da * −1 — ikkalasi ham ishlaydi; bir joyda qiling, ikkala joyda emas.

Save IMC.

2

Pawn va SpringArm rotation sozlamalari

Taxminiy vaqt: 10–15 daqiqa

2.1 BP_Player Class Defaults / Pawn

BP_Player root / Class Defaults da (Pawn bo‘limi):

  • Use Controller Rotation Pitch — odatda false (tana tepaga-pastga burilmasin)
  • Use Controller Rotation Yaw — ko‘pincha false (third person: tana yurishga qaraydi)
  • Use Controller Rotation Roll — false

Character Movement:

  • Orient Rotation to Movement — true (yurish yo‘nalishiga tana)
  • Rotation Rate — default yoki biroz oshirish mumkin
2.2 SpringArm

SpringArm Details:

  • Use Pawn Control Rotation = true ← kamera controller’ga ergashadi
  • Inherit Pitch / Yaw / Roll — odatda default (Pitch+Yaw)

Camera component: Use Pawn Control Rotation odatda false (arm allaqachon aylangan).

3

IA_Look → Yaw va Pitch

Taxminiy vaqt: 15–20 daqiqa

3.1 Event Graph

BP_Player → qidiruv IA_Look → Enhanced Input Action.

Triggered (har frame delta keladi).

Action Value → Break Vector2D → X, Y.

3.2 Controller input 
Triggered
  → Add Controller Yaw Input   (Val = X * MouseSensitivity)
  → Add Controller Pitch Input (Val = Y * MouseSensitivity * -1)

MouseSensitivity — Float variable, default masalan 1.0 yoki 0.5 (sinab ko‘ring).

Add Controller Yaw Input / Pitch Input — Pawn/Character node’lari, Target Self.

Invert Y: Agar sichqoncha yuqoriga surilganda kamera pastga qarasа — * −1 ni olib tashlang yoki qo‘shing. Bu shaxsiy preference.

5

Pitch chegarasi

Taxminiy vaqt: 10–15 daqiqa

5.1 Qayerda sozlanadi?

Variant A — Player Controller

Agar maxsus BP_PlayerController bo‘lsa: Class Defaults → Camera / View Pitch Min & Max.

Hozircha default PlayerController ishlatsangiz — Project Settings yoki runtime da:

Get Player Controller → Cast → set View Pitch Min/Max (ba’zi versiyalarda Player Camera Manager).

Variant B — BeginPlay da PlayerCameraManager

Get Player Camera Manager
  → Set View Pitch Min (−60 yoki −70)
  → Set View Pitch Max (60 yoki 70)

Aniq node nomlari engine versiyasiga qarab farq qilishi mumkin: “Limit View Pitch”, Camera Manager properties.

Tekshirish: Sichqonchani uzoq yuqoriga/pastga torting — ma’lum burchakdan oshmasligi kerak.

6

Mouse sensitivity

Taxminiy vaqt: 5 daqiqa

Keyinroq Settings UI shu variable’ni (yoki Player Settings save) o‘zgartiradi. Hozir Details’dan Instance Editable qilib PIE da sinashingiz mumkin.
