Movement

IA_Move va IA_Jump orqali BP_Player yuradi va sakraydi. WASD + Space.

🎯 Kun maqsadi

  • → IA_Move (Axis2D) va IA_Jump (Digital) yaratasiz
  • → WASD → IA_Move, Space → IA_Jump (IMC)
  • → Add Movement Input + Control Rotation (Forward/Right)
  • → Jump / Stop Jumping
  • → Max Walk Speed = 300, Jump Z Velocity = 420

Bugun qilmang: Sprint / Crouch (Kun 10–11), sichqoncha bilan kamera aylantirish — IA_Look (Kun 12). Faqat yurish + sakrash.

📖 Asosiy tushunchalar

Max Walk Speed

Character Movement’da asosiy yurish tezligi (cm/s). 300 — sekin-o‘rtacha; Sprint keyinroq alohida oshiriladi.

Jump Z Velocity

Sakrashda beriladigan yuqoriga tezlik. 420 — tipik “odamcha” sakrash.

Add Movement Input

Character’ga yo‘nalish + kuch beradi. Direction odatda kamera (Control Rotation) Forward/Right vector; Scale Value −1…1 (input o‘qi).

Axis2D (Vector2D)

IA_Move qiymati: X = o‘ng/chap (A/D), Y = old/orqa (W/S). Bitta Action — to‘rt tugma.

Get Control Rotation

Controller (kamera) qaysi tomonga qaragan. Undan Forward/Right Vector olinadi — “kamera qarab turgan tomonga yur”.

↗ Mantiq sxemasi 

IA_Move (Triggered) → Action Value (Vector2D)
    │
    ├─ Get Control Rotation
    │     ├─ Get Forward Vector → Add Movement Input (WorldDir, Scale = Y)
    │     └─ Get Right Vector   → Add Movement Input (WorldDir, Scale = X)
    │
    └─ (X = Right/Left, Y = Forward/Back)

IA_Jump (Started)    → Jump
IA_Jump (Completed)  → Stop Jumping

2

IMC_BetrayBuilder — WASD va Space

Taxminiy vaqt: 15–20 daqiqa

2.1 IA_Move mapping (4 tugma)

IMC_BetrayBuilder ni oching → Mappings → IA_Move uchun qator qo‘shing (yoki mavjudini tanlang).

Axis2D uchun bir nechta Key bir Action’ga bog‘lanadi, har biri Swizzle / Negate bilan:

Key Modifiers / eslatma
W Y o‘qi + (Forward)
S Y o‘qi − (Negate yoki Swizzle)
A X o‘qi −
D X o‘qi +

UE5 da odatda:

  • Har tugma alohida mapping qatori, bir xil Action = IA_Move
  • Modifiers: Swizzle Input Axis Values (YXZ…) va/yoki Negate
  • Yoki template Third Person IMC’sidan WASD qatorlarini ko‘chirib o‘rganing

Oson yo‘l: Agar loyihada ThirdPerson IMC bo‘lsa, u yerda Move Action qanday map qilinganini ochib ko‘ring — xuddi shu strukturani IA_Move uchun takrorlang.

2.2 IA_Jump → Space

Yangi mapping: Action = IA_Jump, Key = Space Bar

Save IMC.

4

Yurish mantiqi (Add Movement Input)

Taxminiy vaqt: 20–25 daqiqa

4.1 IA_Move event

BP_Player Event Graph → o‘ng sichqoncha → IA_Move → Enhanced Input Action IA_Move

Triggered (yoki Started+Triggered) dan foydalaning — Axis qiymati har freym yangilanadi.

Action Value pin (Vector2D / yellow) chiqadi: X va Y.

4.2 Forward va Right

Triggered execution zanjirida:

  1. Get Control Rotation (Self / Pawn)
  2. Rotation’dan faqat Yaw kerak (ixtiyoriy: Make Rotator, Pitch/Roll = 0) — tik yurish uchun
  3. Get Forward Vector (Rotation)
  4. Get Right Vector (Rotation)
  5. Break Vector2D (Action Value) → X, Y
  6. Add Movement Input — World Direction = Forward, Scale Value = Y
  7. Yana Add Movement Input — World Direction = Right, Scale Value = X

Nima uchun Control Rotation? Kamera qarab turgan tomonga “old” hisoblanadi. Agar Actor Rotation ishlatsangiz, mesh aylanguncha chalkashishi mumkin.

X/Y almashtirilgan bo‘lsa: W chapga yursa — Break’da X/Y ni almashtiring yoki IMC modifier’larni tuzating.
