Stage 4 · Kun 26 · Multiplayer-ready spawn

Spawn Points

Lobby’da 4+ Player Start + GameMode’da tasodifiy tanlash — ustma-ust spawn yo‘q.

🎯 Kun maqsadi

  • → Lobby: kamida 4 Player Start
  • → Bir-biridan yetarli masofa (capsule to‘qnashmasin)
  • → BP_GameMode: Choose Player Start override
  • → Get All Actors of Class → Random index
  • → Qayta Play: turli nuqtalar

Bugun qilmang: Betrayer/Builder alohida spawn (Day 51 role). Faqat umumiy random.

? Nima uchun ko‘p Player Start?

Default: bitta Start — barcha o‘yinchilar bir nuqtada. Multiplayer’da “stack” va collision g‘alati.

Lobby — tabiiy yig‘ilish joyi (Kun 23). 4+ Start = 4 o‘yinchi sinovi uchun yetarli; keyin ko‘paytirasiz.

📍 Player Start nima?

Engine Actor: Player Start. Transform = spawn joyi + yo‘nalish (arrow).

Place Actors → Basic → Player Start. Viewport’da bayroqcha / odam ikonkasi.

Tag / Player Start Tag keyinroq filter uchun (team). Bugun hammasi bir xil class.

G BP_GameMode roli

Day 8: Default Pawn = BP_Player. Spawn joyini tanlash ham GameMode vazifasi.

Funksiya: Choose Player Start (yoki FindPlayerStart / ChoosePlayerStart — versiyaga qarab). Override qilib o‘z logikangizni yozasiz.

🎲 Choose Player Start — g‘oya

Har yangi Pawn spawn bo‘lganda engine “qayer?” deb so‘raydi. Siz array’dan random qaytarasiz.

Murakkabroq (keyin): band nuqtalarni chiqarib tashlash, eng uzoq Start, team tag. Bugun: oddiy random.

Lobby’ga 4 Player Start

15–20 daqiqa

Place Actors → Player Start × 4. Lobby polida, burchaklar yoki kvadrat grid.

Arrow yo‘nalishi: xona markaziga yoki eshik tomon — birinchi nazar.

2

Masofa

10 daqiqa

Kamida ~150–200 unit oralig‘i (capsule radius 42 × 2 + bo‘shliq). Ustma-ust = physics “portlash”.

Outliner: PS_Lobby_01 … 04.

3

Choose Player Start override

15–25 daqiqa

BP_GameMode oching → Functions / Override → Choose Player Start (yoki Find Player Start — docs).

Agar ro‘yxatda topilmasa: Class Settings / parent AGameModeBase funksiyalarini qidiring.

Return type: Actor (Player Start).

4

Random tanlash mantiq

20–30 daqiqa

Get All Actors of Class (PlayerStart)
→ Length
→ Max = Length - 1 (Branch Length > 0)
→ Random Integer 0..Max
→ Get copy from array
→ Return

Length == 0 → Parent Choose Player Start
  yoki Get Actor of Class default

Compile. Empty array crash oldini oling.

5

World Settings

5 daqiqa

MAP_BetrayBuilder → World Settings → GameMode Override = BP_GameMode.

6

Play test

15–20 daqiqa

★

Challenge — Hallway fallback

Hallway’ga 2 Start qo‘ying. Tag: Lobby vs Fallback.

Avval Lobby tag’li array; bo‘sh bo‘lsa Fallback. Yoki 90% Lobby random.

Oddiy variant: barcha Start bir array — Hallway ham aralashsin.

Troubleshooting

Doim bir joy: Override chaqirilmayapti? GameMode to‘g‘rimi? PIE default GM?

Null return: Array bo‘sh — levelda Player Start bormi?

Devor ichida: Start transform Z / collision.

Find vs Choose: Parent class hujjatiga qarang; ikkalasidan biri override qilinadi.

FAQ

Listen Server 2 o‘yinchi?
Har biri Choose chaqiriladi — turli random. Band filter keyin.
Player Start Emplaced?
Default class yetarli. Custom subclass tag uchun ixtiyoriy.
Restart Player?
O‘limdan keyin yana Choose ishlaydi — xuddi shu mantiq.
