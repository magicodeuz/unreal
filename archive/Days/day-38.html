Timer

Round uchun umumiy vaqt — masalan 10 daqiqa. Vaqt tugasa, Lose (yoki boshqa) shart ishga tushadi.

600
Default (soniya)
1s
Tick interval
OnTimeUp
Event
~30
Daqiqa

Bugungi aniq maqsad

Round uchun umumiy vaqt hisoblagichini yaratish. Set Timer by Event + countdown + OnTimeUp (hozircha Print String).

01 Nima uchun Timer kerak?

Betray / social deduction o‘yinlarida vaqt bosimi muhim: o‘yinchilar shoshiladi, Betrayer vaqtni ishlatadi, objective’lar muddatga bog‘liq. Timer — bu bosimning texnik asosi.

Keyinroq UI da ko‘rsatiladi, 0 da Lose Condition chaqiriladi, yoki “oxirgi daqiqa” audio/efekt.

Professor eslatmasi

Tick da har frame RemainingTime kamaytirish ham mumkin, lekin Set Timer by Event (1 soniya) aniqroq va arzonroq. O‘yin pauza qilinsa, timer handle ni to‘xtatish oson.

02 Nazariya — Set Timer by Event

Set Timer by Event — belgilangan vaqt oralig‘ida (masalan 1.0 soniya) Custom Event ni takroriy chaqiradi. Looping = true bo‘lsa, to‘xtatmaguncha davom etadi.

Countdown mantiq: har chaqiriqda RemainingTime -= 1. 0 yoki undan past — Clear Timer + OnTimeUp.

03 Variable’lar

Nom Tip Izoh
RemainingTime Float Default 600 (10 daqiqa)
TimerHandle Timer Handle Clear / Pause uchun

BP_GameMode yoki Game State — eng to‘g‘ri joy (butun raund uchun umumiy).

04 Timer ishga tushirish 

// BP_GameMode → BeginPlay (yoki StartRound)

1. RemainingTime = 600   // yoki 30 test uchun
2. Set Timer by Event
   - Event: UpdateTimer (Custom Event)
   - Time: 1.0
   - Looping: true
   - Return Value → TimerHandle ga saqlang

05 UpdateTimer + OnTimeUp 

// Custom Event: UpdateTimer

1. RemainingTime = RemainingTime - 1
2. Print String: RemainingTime (yoki Format: MM:SS)
3. Branch: RemainingTime <= 0
   True:
     - Clear Timer by Handle (TimerHandle)
     - Call OnTimeUp (Custom Event)
   False:
     - (hech narsa — keyingi soniya kutadi)

// Custom Event: OnTimeUp
1. Print String: "VAQT TUGADI!" (qizil)
// Keyinroq: Lose Condition, UI, va hokazo

06 Amaliy qadamlar

Variable’lar

  1. BeginPlay da Set Timer by Event → UpdateTimer, 1.0, Looping
  2. Return Value ni TimerHandle ga yozing

Tez test (Challenge)

  1. RemainingTime = 30 qilib Play
  2. 30 soniyada OnTimeUp ishlashini ko‘ring
  3. Keyin 600 ga qaytaring

08 Keng tarqalgan xatolar

1. Timer ikki marta ishlayapti

BeginPlay qayta chaqirilsa yangi timer qo‘shiladi. Avval Clear qiling yoki Handle borligini tekshiring.

2. 0 ga yetganda to‘xtamayapti

Clear Timer by Handle ga to‘g‘ri Handle uzating. Looping timer Clear qilinmasa davom etadi.

3. Print juda ko‘p

Test uchun qoldiring; keyin olib tashlang yoki faqat har 10 soniyada Print qiling.

★ Professor izohi
