Stage 1 · Kun 1 / 7

Unreal Engine bilan tanishish

Bugun kod yozmaymiz. Maqsad — Unreal Editor muhitini tushunish, loyiha yaratish va asosiy panellar bilan ishlashni o‘rganish.

🎯 Kun maqsadi

Kursning birinchi kunida siz:

  • → Unreal Engine 5 ni ochib, yangi loyiha yaratasiz
  • → Editor interfeysining asosiy panellarini tanib olasiz
  • → Loyiha uchun papka strukturasini yaratasiz
  • → Bo‘sh Level yaratib, unga oddiy shakllar joylashtirasiz
  • → Transform (Location, Rotation, Scale) bilan ishlashni sinab ko‘rasiz

Eslatma: Bugun Blueprint, C++, Material yoki boshqa murakkab narsalarga tegmang. Faqat muhitni o‘rganing.

📖 Asosiy tushunchalar

Bu so‘zlarni bugun eslab qoling — butun kurs davomida ishlatiladi.

Project

Butun o‘yiningizni saqlaydigan konteyner. Ichida Level’lar, Blueprint’lar, materiallar, audio — hammasi bor. Bir Project = bitta o‘yin.

Level (Map)

O‘yin bo‘lib o‘tadigan joy. Xona, bino, ochiq maydon — bularning hammasi Level. Bitta Project’da ko‘p Level bo‘lishi mumkin (masalan: MainMenu, Lobby, GameMap).

Actor

Level ichiga qo‘yiladigan har qanday narsa. Kub, chiroq, eshik, o‘yinchi, kamera — bularning hammasi Actor. Har bir Actor’ning o‘z Transform’i (joylashuvi) bor.

Component

Actor ichidagi kichik qism. Masalan: Static Mesh Component (3D model), Collision Component (fizik chegara), Light Component (yorug‘lik). Actor = Component’lar yig‘indisi.

Content Browser

Barcha fayllaringizni ko‘rsatadigan panel (pastda yoki yon tomonda). Papkalar, Blueprint’lar, materiallar, texture’lar shu yerda turadi. Windows’dagi File Explorer’ga o‘xshaydi.

Viewport

3D dunyoni ko‘rish oynasi. Sichqoncha bilan aylanasiz, WASD bilan harakatlanasiz (Editor rejimida). O‘yinni Play qilganda ham shu oynada ko‘rinadi.

Details

Tanlangan Actor’ning barcha sozlamalari shu panelda. Location, Rotation, Scale, material, collision va boshqa parametrlar.

Transform

Actor’ning 3 ta asosiy xususiyati: Location (qayerda turibdi), Rotation (qaysi tomonga qaragan), Scale (qanchalik katta).

⚙️ Talablar

  • ✓
    Unreal Engine 5.3 yoki undan yuqori

    Epic Games Launcher orqali o‘rnatilgan bo‘lishi kerak. Agar yo‘q bo‘lsa — unrealengine.com/download

  • ✓
    Kamida 20–30 GB bo‘sh joy

    Engine + Project + Cache uchun.

  • ✓
    8 GB RAM (tavsiya: 16 GB+)

    Kamroq bo‘lsa ishlaydi, lekin sekinroq bo‘lishi mumkin.

1

Yangi loyiha yaratish

Taxminiy vaqt: 5–10 daqiqa

1.1 Epic Games Launcher’ni oching

Kompyuteringizda Epic Games Launcher dasturini ishga tushiring. Agar yo‘q bo‘lsa, avval o‘rnating.

Chap menyudan Unreal Engine bo‘limini bosing. Keyin yuqoridagi Library tab’iga o‘ting.

Ko‘rinishi: Library’da o‘rnatilgan Engine versiyalari (masalan 5.4, 5.5) ro‘yxati chiqadi. Har birining yonida Launch tugmasi bor.

1.2 Engine’ni ishga tushiring

O‘rnatilgan UE5 versiyangizning yonidagi Launch tugmasini bosing.

Bir necha soniya (yoki bir daqiqagacha) kutasiz — Engine yuklanadi va Project Browser oynasi ochiladi.

Agar birinchi marta ochayotgan bo‘lsangiz: “Shaders compiling” degan xabar chiqishi mumkin. Bu normal — 5–15 daqiqa kutishingiz mumkin. Keyingi safar tezroq ochiladi.

1.3 Template tanlash

Project Browser oynasida chap tomonda GAMES kategoriyasi tanlanganligiga ishonch hosil qiling.

Ro‘yxatdan Third Person template’ini tanlang (odamcha ko‘rinishidagi ikonka).

GAMES
→ Third Person ← mana shuni tanlang
First Person
Top Down
Blank
...

Nima uchun Third Person? Chunki Betray Builder third-person kamera bilan ishlaydi, va bu template’da allaqachon Character, Camera, Input tayyor turadi. Keyinroq o‘zimiznikiga almashtiramiz, lekin boshlash uchun qulay.

1.4 Loyiha sozlamalari

O‘ng pastki qismda loyiha parametrlarini to‘ldiring:

Maydon Qiymat Izoh
Project Name BetrayBuilder Bo‘sh joy va maxsus belgilar qo‘ymang
Project Location Istalgan papka Masalan: D:\UE_Projects\
Blueprint / C++ Blueprint C++ tanlamang — bu kurs Blueprint asosida
Target Platform Desktop Standart qoldiring

Hammasi to‘g‘ri bo‘lgach, Create tugmasini bosing.

Kutish: Birinchi marta loyiha yaratilganda shader’lar kompilyatsiya qilinadi. Bu 5–20 daqiqa davom etishi mumkin. Ekranda “Compiling Shaders” progress ko‘rinadi. Kutib turing, yopmang.

1.5 Editor ochilganini tasdiqlang

Muvaffaqiyatli bo‘lsa, to‘liq Unreal Editor oynasi ochiladi. O‘rtada 3D Viewport, atrofida panellar ko‘rinadi.

Template tufayli allaqachon bitta Level ochiq bo‘ladi (ThirdPersonMap) va unda Mannequin (odam modeli) turadi. Bu normal.

Tekshirish: Agar Viewport’da 3D sahna ko‘rinsa va yuqorida toolbar (Play tugmasi va h.k.) bo‘lsa — hammasi joyida. Keyingi bosqichga o‘ting.

2

Editor interfeysini tushunish

Taxminiy vaqt: 15–20 daqiqa

Unreal Editor bir nechta asosiy panelga bo‘lingan. Har birini alohida ko‘rib chiqamiz. Panellar joylashuvini keyinroq o‘zgartirish mumkin, lekin hozircha standart layout bilan ishlaymiz.

Viewport (markaziy oyna)

Bu — 3D dunyoni ko‘radigan asosiy maydon. Hozir unda template’ning sahnasi turibdi.

Harakatlanish (Editor rejimida):

  • O‘ng sichqoncha + WASD — uchib yurish (fly mode)
  • O‘ng sichqoncha + sichqoncha harakati — atrofga qarash
  • Chap sichqoncha — obyektni tanlash
  • O‘rta sichqoncha (scroll bosib) — pan (siljitish)
  • Scroll g‘ildirak — yaqinlashish / uzoqlashish
  • F — tanlangan obyektga fokus (frame)
  • Alt + Chap sichqoncha — orbit (aylanish)

Mashq: Hozir Viewport’da o‘ng sichqonchani bosib turing va WASD bilan atrofda uchib ko‘ring. Keyin biror obyektni chap sichqoncha bilan tanlang va F bosing — kamera unga yaqinlashadi.

Content Browser (odatda pastki qism)

Barcha asset’laringiz (fayllar) shu yerda. Chapda papka daraxti, o‘ngda tanlangan papkadagi fayllar.

Agar ko‘rinmasa: yuqoridagi menyudan Window → Content Browser → Content Browser 1 ni tanlang.

Muhim tugmalar:

  • Add (yashil +) — yangi asset yaratish (Blueprint, Material, Level...)
  • Import — tashqi fayl (FBX, PNG, WAV...) yuklash
  • Save All (Ctrl+Shift+S) — barcha o‘zgarishlarni saqlash

Content Browser’da hozir Content ildiz papkasi va uning ichida template papkalari (Characters, Input, LevelPrototyping...) ko‘rinadi. Ularga tegmang — o‘z papkalarimizni yaratamiz.

Details (odatda o‘ng tomon)

Viewport’da biror Actor’ni tanlaganingizda, uning barcha sozlamalari shu panelda chiqadi.

Eng muhim bo‘lim — Transform:

  • Location — X, Y, Z koordinatalari (qayerda turibdi)
  • Rotation — Pitch, Yaw, Roll (qaysi tomonga aylangan)
  • Scale — X, Y, Z o‘lchami (1.0 = asl o‘lcham)

Qiymatlarni qo‘lda yozishingiz yoki Viewport’dagi gizmo (o‘qlar) bilan sichqoncha orqali o‘zgartirishingiz mumkin.

World Outliner (odatda o‘ng yuqori)

Joriy Level’dagi barcha Actor’larning ro‘yxati. Viewport’da topish qiyin bo‘lgan obyektni shu yerdan nomiga qarab topib, tanlash mumkin.

Actor’ni tanlash → Details panelida sozlamalari ochiladi. O‘ng tugma → Delete, Rename, Edit va h.k.

Toolbar (yuqori qism)

Eng muhim tugmalar:

  • Save — joriy Level’ni saqlash
  • Play ▸ — o‘yinni ishga tushirish (PIE — Play In Editor)
  • Stop ■ — o‘yinni to‘xtatish (Play paytida chiqadi)
  • Selection Mode / Landscape / Foliage... — turli ish rejimlari (hozircha Selection Mode’da qoling)

Mashq: Yuqoridagi Play tugmasini bosing. O‘yin ishga tushadi — WASD bilan yurasiz, sichqoncha bilan qaraysiz. Chiqish uchun Esc bosing yoki toolbar’dagi Stop’ni bosing.

Place Actors panel (chap tomon, ba’zan yashirin)

Level’ga yangi Actor qo‘yish uchun ishlatiladi. Agar ko‘rinmasa: Window → Place Actors.

Ichida kategoriyalar bor: Basic (Cube, Sphere, Cylinder...), Lights, Visual Effects, Volumes va h.k.

Keyingi bosqichda aynan shu paneldan foydalanamiz.

3

Papka strukturasini yaratish

Taxminiy vaqt: 5–10 daqiqa

3.1 Content ildizida asosiy papkani yaratish

Content Browser’da chapdagi papka daraxtida Content ni tanlang (ildiz).

Bo‘sh joyda o‘ng sichqoncha bosing → New Folder.

Papka nomini yozing: BetrayBuilder

Nima uchun alohida papka? Template’ning o‘z papkalari bor. Bizning barcha ishimizni Content/BetrayBuilder/ ichida saqlaymiz — chalkashib ketmaslik uchun.

3.2 Ichki papkalarni yaratish

BetrayBuilder papkasiga kiring. Ichida quyidagi papkalarni birma-bir yarating (har biri uchun o‘ng sichqoncha → New Folder):

Content/
└── BetrayBuilder/
├── Maps/
├── Blueprints/
├── Characters/
├── UI/
├── Materials/
├── Audio/
└── Props/

Har bir papkaning vazifasi:

  • Maps — barcha Level’lar (xaritalar)
  • Blueprints — umumiy Blueprint’lar, System’lar, Interaction
  • Characters — Player, AI Character’lar
  • UI — Widget’lar (HUD, Menu, Inventory...)
  • Materials — Material va Material Instance’lar
  • Audio — Sound Wave, Sound Cue, Music
  • Props — dekorativ Static Mesh’lar, item’lar

Tekshirish: Content Browser’da Content/BetrayBuilder/ ichida 7 ta papka ko‘rinishi kerak. Agar ko‘rinsa — keyingi bosqichga o‘ting.

4

Yangi Level yaratish

Taxminiy vaqt: 5 daqiqa

4.1 Empty Level yaratish

Yuqoridagi menyudan: File → New Level...

Ochilgan oynada Empty Level ni tanlang (ba’zi versiyalarda “Empty Open World” yoki “Basic” ham bor — bizga oddiy Empty Level kerak).

Create bosing.

Viewport endi deyarli qora/bo‘sh bo‘ladi — bu normal. Hech narsa yo‘q, chunki Empty Level.

4.2 Level’ni saqlash

Ctrl + S bosing (yoki File → Save Current Level).

Saqlash oynasi ochiladi. Chapda papka daraxtidan Content → BetrayBuilder → Maps ni tanlang.

Fayl nomi: MAP_Day01

Save bosing.

Nomlash konvensiyasi: Kurs davomida Level’lar MAP_ prefiksi bilan nomlanadi (MAP_Day01, MAP_BetrayBuilder, MAP_MainMenu...). Bu Content Browser’da tez topish uchun.

Tekshirish: Content Browser’da Content/BetrayBuilder/Maps/MAP_Day01 ko‘rinishi kerak. Viewport yuqorisida ham Level nomi chiqadi.

5

Oddiy shakllarni joylashtirish

Taxminiy vaqt: 10–15 daqiqa

5.1 Place Actors panelini ochish

Agar chapda Place Actors paneli ko‘rinmasa:

Window → Place Actors ni bosing. Panel ochiladi.

Ichida Basic kategoriyasini tanlang (yoki qidiruvga “Cube” yozing).

5.2 Cube qo‘yish
  1. Cube ni toping (Basic Shapes ichida).
  2. Uni sichqoncha bilan ushlab, Viewport’ga sudrab tashlang (drag & drop).
  3. Cube Viewport’da paydo bo‘ladi. Uni tanlangan holatda qoldiring (sariq/oranq chegara bilan ajralib turadi).

Muammo: Agar Cube “erda” emas, osmonda yoki uzoqda paydo bo‘lsa — tanlang va F bosing (fokus). Yoki Details’da Location X/Y/Z ni 0, 0, 100 qilib qo‘ying.

5.3 Sphere va Cylinder qo‘yish

Xuddi shu usulda:

  1. Sphere ni Viewport’ga sudrab tashlang.
  2. Cylinder ni ham sudrab tashlang.

Uchala shakl ham Viewport’da ko‘rinishi kerak. Agar bir-birining ustiga tushib qolsa — keyingi bosqichda joyini o‘zgartiramiz.

Tekshirish: World Outliner’da 3 ta Actor ko‘rinishi kerak: Cube, Sphere, Cylinder (yoki StaticMeshActor_...). Agar ko‘rinsa — yaxshi.

6

Transform bilan ishlash

Taxminiy vaqt: 15 daqiqa

6.1 Gizmo rejimlarini bilish

Viewport yuqorisida (yoki o‘ng yuqori burchakda) 3 ta muhim rejim tugmasi bor:

  • W — Translate (ko‘chirish). Qizil/yashil/ko‘k o‘qlar chiqadi.
  • E — Rotate (aylantirish). Doira shaklidagi gizmo.
  • R — Scale (kattalashtirish/kichraytirish). Kubchalar chiqadi.

Actor’ni tanlang → W bosing → o‘qlarni ushlab sudrab, joyini o‘zgartiring.

6.2 Details orqali aniq qiymat berish

Cube’ni tanlang. O‘ngdagi Details panelida Transform bo‘limini toping.

Quyidagi qiymatlarni qo‘lda yozib ko‘ring (misol):

Actor Location (X, Y, Z) Scale (X, Y, Z)
Cube 0, 0, 50 1.5, 1.5, 1.5
Sphere 200, 0, 50 1.0, 1.0, 1.0
Cylinder -200, 0, 100 1.0, 1.0, 2.0

Qiymatni yozgach Enter bosing — Actor darhol shu joyga ko‘chadi.

Maslahat: Scale’da qulf ikonkasini ochsangiz (Unlock), X/Y/Z ni alohida o‘zgartirish mumkin. Yopiq bo‘lsa — birini o‘zgartirsangiz, hammasi bir xil o‘zgaradi.

6.3 Rotation sinab ko‘rish

Cylinder’ni tanlang → E (Rotate mode) → gizmo doiralarini ushlab aylantiring.

Yoki Details’da Rotation → Yaw qiymatini 45 deb yozing — 45 gradus aylanadi.

Bu keyinroq eshik ochilishi (Yaw 0→90) kabi animatsiyalarda ishlatiladi. Hozircha faqat tanishib chiqing.

7

Test qilish

Taxminiy vaqt: 5 daqiqa

Play orqali tekshirish
  1. Yuqoridagi toolbar’dan Play ▸ tugmasini bosing (yoki Alt + P).
  2. O‘yin ishga tushadi. Kamera harakat qilishi kerak (WASD + sichqoncha).
  3. Viewport’da uchta shakl (Cube, Sphere, Cylinder) ko‘rinib turishi kerak.
  4. Chiqish: Esc yoki toolbar’dagi Stop.

Muvaffaqiyat mezonlari:

  • ✓ Unreal Editor ochiladi va asosiy panellarni tanib olasiz
  • ✓ BetrayBuilder project yaratilgan va papka strukturasi tayyor
  • ✓ Level’da 3 ta oddiy shakl joylashtirilgan
  • ✓ Play bosganda shakllar ko‘rinadi va kamera ishlaydi

Agar Play bosganda hech narsa ko‘rinmasa:

  • Shakllar juda uzoqda bo‘lishi mumkin — Outliner’dan tanlab F bosing
  • Level saqlanmagan bo‘lishi mumkin — Ctrl+S
  • Yorug‘lik yo‘qligi sababli qorong‘u bo‘lishi mumkin — Place Actors → Lights → Directional Light qo‘ying
★

Challenge (ixtiyoriy)

Qo‘shimcha mashq

Asosiy vazifalar tugagach, quyidagini sinab ko‘ring:

  1. Content Browser’da Content/BetrayBuilder/ ichida yana bitta papka yarating: Systems.
  2. Shu papka ichiga kiring.
  3. O‘ng sichqoncha → Blueprint Class → ochilgan oynada Actor ni tanlang → nomini BP_Sandbox qiling.
  4. Yaratilgan Blueprint’ni ikki marta bosib oching — Blueprint Editor ochiladi. Hozircha hech narsa yozmang, faqat yoping.

Bu challenge’ning maqsadi — papka yaratish va oddiy Blueprint asset yaratish jarayonini bir marta ko‘rish. Keyingi kunlarda shu yerda ko‘p ishlaymiz.
