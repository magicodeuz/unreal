Stage 1 · Kun 6 / 7

Input System

Enhanced Input orqali Interact, Sprint, Crouch amallarini sozlaysiz. Oddiy Keyboard Event o‘rniga professional, qayta sozlanadigan tizim.

🎯 Kun maqsadi

Bugun siz:

  • → 3 ta Input Action: IA_Interact, IA_Sprint, IA_Crouch
  • → IMC_BetrayBuilder Mapping Context yaratasiz
  • → E / Left Shift / Left Ctrl ni Action’larga bog‘laysiz
  • → Character BeginPlay’da Add Mapping Context qilasiz
  • → Har bir Action uchun vaqtinchalik Print String qo‘yasiz

Bugun yozmang: Sprint tezligi, Crouch capsule — Kun 10–11. Faqat input “signal”lari ishlasin.

📖 Asosiy tushunchalar

Enhanced Input

UE5’ning zamonaviy input tizimi. Eski “Axis/Action Mapping” (Project Settings) o‘rniga asset asosida ishlaydi: qayta sozlash, bir nechta qurilma, trigger’lar (Started, Triggered, Completed) qulay.

Input Action (IA)

Bitta o‘yin amali — “Interact”, “Sprint”, “Jump”. Tugma emas, ma’no. Value Type: Digital (bosildi/bosilmadi), Axis1D, Axis2D (WASD, sichqoncha).

Input Mapping Context (IMC)

Qaysi tugma qaysi IA’ga bog‘langanini saqlaydigan “xarita”. Masalan: E → IA_Interact. Bir nechta IMC bo‘lishi mumkin (o‘yin / UI / avtomobil) — keragida qo‘shiladi/olib tashlanadi.

Add Mapping Context

Player Controller (yoki Local Player) ga IMC’ni faollashtirish. Odatda Character yoki Player Controller BeginPlay’da chaqiriladi. Priority: bir nechta context bo‘lsa qaysi ustun.

Trigger’lar (qisqacha)

Started — tugma endi bosildi · Triggered — faol (bosib turilganda takrorlanishi mumkin) · Completed — qo‘yib yuborildi · Canceled — bekor. Challenge’da Started/Completed farqini ko‘rasiz.

⚙️ Oldindan talab

  • ✓ Third Person (yoki o‘zingizning) Character Blueprint
  • ✓ Enhanced Input plugin yoqilgan (UE5 da odatda default)

Plugin: Edit → Plugins → “Enhanced Input” enabled. O‘chirilgan bo‘lsa yoqing va Editor’ni qayta ishga tushiring.

1

Input papkasi va 3 ta Input Action

Taxminiy vaqt: 15 daqiqa

1.1 Papka

Content/BetrayBuilder/Blueprints/ ichida Input papkasini yarating.

(Yoki Content/BetrayBuilder/Input — muhimi izchil saqlash.)

1.2 Input Action yaratish

Papkada o‘ng sichqoncha → Input → Input Action

(Ba’zi versiyalarda: Miscellaneous yoki to‘g‘ridan-to‘g‘ri “Input Action”.)

Uchta asset, nomlar:

  • IA_Interact
  • IA_Sprint
  • IA_Crouch
1.3 Value Type: Digital (Bool)

Har bir IA’ni oching → Details:

Value Type = Digital (bool)

Bu tugma bosilgan/bosilmagan signal. (WASD keyinroq Axis2D — Kun 9.)

Qolgan sozlamalar default qolishi mumkin. Save.

Tekshirish: Input papkasida 3 ta Input Action ko‘rinsin.

2

IMC_BetrayBuilder

Taxminiy vaqt: 5 daqiqa

2.1 Mapping Context yaratish

Xuddi shu Input papkasida: o‘ng sichqoncha → Input → Input Mapping Context

Nom: IMC_BetrayBuilder

Ochilganda “Mappings” ro‘yxati bo‘sh bo‘ladi — keyingi qadamda to‘ldiramiz.

3

Tugmalarni Action’larga bog‘lash

Taxminiy vaqt: 15–20 daqiqa

3.1 Yangi mapping qatorlari

IMC_BetrayBuilder ni oching.

Mappings → + (Add) — uch marta, har bir IA uchun.

3.2 Har bir qatorni sozlash
Input Action Key
IA_Interact E
IA_Sprint Left Shift
IA_Crouch Left Ctrl

Har qatorda:

  1. Action dropdown → mos IA asset
  2. Key / Keyboard → E, Left Shift, Left Control (ro‘yxatdan tanlang yoki klavishani bosing, agar “listen” bo‘lsa)

Save IMC.

Triggers (ixtiyoriy): Mapping ichida Triggers qo‘shish mumkin (Pressed, Released...). Default ko‘pincha yetarli; Challenge’da Started/Completed event tomonda sinanadi.

4

Character’ga Mapping Context qo‘shish

Taxminiy vaqt: 15–20 daqiqa

4.1 Character Event Graph — BeginPlay

Asosiy Character’ni oching (masalan BP_ThirdPersonCharacter).

Event Graph → Event BeginPlay (mavjud zanjirga qo‘shing yoki yangi).

4.2 Add Mapping Context zanjiri

Tipik node ketma-ketligi:

  1. Get Controller → Cast To Player Controller (yoki to‘g‘ridan-to‘g‘ri Get Player Controller)
  2. Get Enhanced Input Local Player Subsystem (Player Controller dan yoki Local Player orqali)
  3. Subsystem → Add Mapping Context
  4. Mapping Context: IMC_BetrayBuilder asset’ini ulang
  5. Priority: masalan 0

Template eslatmasi: Third Person allaqachon o‘z IMC’sini qo‘shishi mumkin. Siznikini qo‘shimcha Add qiling — o‘yinchi ham template input, ham IA_Interact/Sprint/Crouch oladi. Keyinroq bitta IMC’da birlashtirish mumkin.

Compile + Save Character.

5

Event Graph’da Input Action event’lari

Taxminiy vaqt: 15 daqiqa

5.1 IA event node qo‘shish

Character Event Graph’da o‘ng sichqoncha → qidiruv: IA_Interact

Enhanced Input Action IA_Interact (yoki “Input Action IA_Interact”) ni tanlang.

Node’da trigger pin’lari: Started, Triggered, Completed, Canceled...

Triggered dan → Print String → Interact bosildi

5.2 Sprint va Crouch

Xuddi shu tartibda:

  • IA_Sprint → Triggered → Print Sprint
  • IA_Crouch → Triggered → Print Crouch

Compile + Save.

Triggered va bosib turish: Digital action’da Triggered ba’zan bir marta, ba’zan hold paytida qaytarilishi konfiguratsiyaga bog‘liq. Asosiy narsa — E/Shift/Ctrl signal berishi.

6

Test qilish

Taxminiy vaqt: 5–10 daqiqa

Play
  1. Play bosing.
  2. E — “Interact bosildi”
  3. Left Shift — “Sprint”
  4. Left Ctrl — “Crouch”

Muvaffaqiyat: 3 ta IA + 1 ta IMC tayyor; Character’ga input ulangan.

Ishlamasa:

  • BeginPlay’da Add Mapping Context chaqirilganmi?
  • IMC’da to‘g‘ri IA va Key bog‘langanmi?
  • Event node aynan shu IA asset’ga ulanganmi?
  • Enhanced Input plugin yoqilganmi?
  • PIE fokusida boshqa widget input’ni “yutib” yubormayaptimi?
★

Challenge — Started vs Completed

IA_Interact trigger farqi

IA_Interact event node’da:

  • Started → Print Interact Started
  • Completed → Print Interact Completed

Play: E ni bosib turing, keyin qo‘yib yuboring.

Started — bosish boshida bir marta; Completed — qo‘yib yuborganda. Sprint (bosib turib yugurish) va Interact (bir marta faollashtirish) uchun qaysi trigger mosligini o‘ylab ko‘ring.
