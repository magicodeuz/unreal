Asosiy vazifa

Taxminiy vaqt: 30–60 daqiqa (o‘zingiz)

  1. Levelga BP_TestObject (yoki Mesh’li Actor) dan bitta instance joylashtiring.
  2. Mantiqni shu Actor’ning o‘z Event Graph’ida yozing (Player’da Cast/Interface emas — hali Interaction System yo‘q).
  3. IA_Interact (E) Triggered (yoki Actor ichida Enable Input + IA / Keyboard E) bosilganda:
    • birinchi bosish → Cube yashirin + collision o‘chiq
    • ikkinchi bosish → yana ko‘rinadi + collision yoqiladi
    • keyingi bosishlar — shu holatni almashtirib turadi
  4. Faqat shu hafta node’lari: Variable, Branch yoki Flip Flop, Set Actor Hidden In Game, Set Actor Enable Collision, Input.

Test: Play → E ni 4–5 marta bosing. Cube muammosiz ko‘rinadi / yo‘qoladi.

💡 Ishora (kichik spoiler)

Bosib ochish — hali yechim emas ▼ ▲

Ikki yo‘l:

A) Boolean bIsHidden → Branch → true/false da Hidden + Collision → oxirida Boolean’ni teskari qiling (NOT + Set).

B) Flip Flop node — har chaqiruvda A va B ni almashtiradi. A = yashir, B = ko‘rsat.

Node nomlari: Set Actor Hidden In Game, Set Actor Enable Collision (Target: Self).

Input: Actor’da IMC + IA_Interact yoki Enable Input + E; yoki Character’dan Interface (lekin vazifa — o‘z graph’ida).

🔓 Yechim (faqat tiqilib qolsangiz)

Yechimni ochish — o‘zingiz urinib ko‘rgandan keyin

Yechim 1 — Boolean + Branch

// Variable: bIsHidden (Boolean, default false)

IA_Interact (Triggered)  // yoki Keyboard E / OnActivate
    │
    ▼
Branch (Condition: bIsHidden)
    │
    ├─ True  → Set Actor Hidden In Game (False)
    │          Set Actor Enable Collision (True)
    │          Set bIsHidden = False
    │
    └─ False → Set Actor Hidden In Game (True)
               Set Actor Enable Collision (False)
               Set bIsHidden = True

Yoki Branch o‘rniga: Get bIsHidden → NOT → Set Hidden / Collision shu qiymat bilan → Set bIsHidden NOT natijasi.

Yechim 2 — Flip Flop (Challenge)

IA_Interact (Triggered)
    │
    ▼
Flip Flop
    ├─ A → Set Actor Hidden In Game (True)
    │      Set Actor Enable Collision (False)
    │
    └─ B → Set Actor Hidden In Game (False)
           Set Actor Enable Collision (True)

Boolean variable shart emas — Flip Flop ichida holat saqlaydi.

Input eslatmasi: BP_TestObject input olishi uchun BeginPlay → Enable Input + Get Player Controller. Yoki Character’da IA_Interact Triggered → Interface Message OnActivate, va OnActivate ichida yuqoridagi Toggle. Vazifa “o‘z graph” deb aytgani uchun Enable Input + IA yoki Keyboard E qulayroq.

★ Bonus mashqlar (ixtiyoriy)

Vaqt va ishtiyoq bo‘lsa — Stage 2 ga kirishdan oldin.

B1 Rang o‘zgarishi

Toggle bilan birga: yashirin bo‘lmaganda Static Mesh’ga Dynamic Material Instance orqali rang bering (yoki ikkita Material — oddiy / “active”). Yashirin paytda o‘zgartirish shart emas.

B2 ClickCount + chegara

Har E da ClickCount +1. Agar ClickCount ≥ 10 bo‘lsa — Print “Limit” va boshqa toggle qilmang (Branch). Reset uchun R tugmasi (yangi IA yoki Keyboard).

B3 Ikki obyekt, bitta Interface

Kun 5 dagi BPI_TestInterface + Player’dan Message: E bosilganda nishonga (reference yoki Get All) OnActivate → har obyekt o‘z toggle’ini qilsin. Bu Stage 3 Interaction’ga eng yaqin bonus.

B4 Qisqa yozma

5–10 jumla: “Cast qachon hali ham kerak, Interface qachon afzal?” — Kun 5 challenge’ni yangilang. Keyingi haftalar uchun o‘zingizga eslatma.
