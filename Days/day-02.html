KUN 2 / 90 STAGE 1 · FUNDAMENTALS HIERARCHY

Actor va Component

Birinchi Blueprint Actor — va uning ichidagi daraxt: Root → Mesh → Collision. Hali Event Graph yo‘q. Faqat tuzilma.

Bugungi aniq maqsad

BP_TestObject yaratish: Static Mesh (Cube) + Box Collision. Parent/Child bog‘lanishini tushunish. Levelga 2–3 nusxa qo‘yish.

01 Metafora: uy va xonalar

Actor — butun uy. Level ga qo‘yiladigan bitta “narsa”. Component — uyning xonalari va jihozlari: devor (Mesh), eshik chegarasi (Collision), lampochka (Light).

Uy ko‘chsa — xonalar ham ko‘chadi. Bu Parent / Child: Parent harakatlansa, Child ham u bilan birga ketadi. Collision ni Mesh ga “bog‘lab” qo‘ysangiz, Mesh o‘zgarsa Collision ham joyida qoladi.

02 Component daraxti (bugungi maqsad)

DefaultSceneRoot
│
├─ StaticMeshComponent ← ko‘rinadigan Cube
│
└─ BoxCollision ← fizik chegara (biroz kattaroq)
Challenge: + Point Light

Components panelida (Blueprint editor chap tomonda) shu daraxt ko‘rinadi. Drag qilib Parent ni o‘zgartirish mumkin.

03 Mesh vs Collision — nima farqi?

Static Mesh
  • Ko‘z bilan ko‘rasiz
  • Cube / Sphere mesh tanlanadi
  • “Chiroyli quti”
Box Collision
  • Odatda ko‘rinmaydi (Show Collision)
  • Fizika, Overlap, Hit
  • “Teginish chegarasi”

Keyinchalik Interaction (Line Trace, Overlap) aynan Collision bilan ishlaydi. Bugun faqat qo‘yib, kattalashtirib, ko‘rib chiqamiz.

04 Amaliy qadamlar

1

BP_TestObject yaratish

  1. Content Browser → Blueprints (yoki BetrayBuilder/Blueprints).
  2. Right-click → Blueprint Class → Actor.
  3. Nom: BP_TestObject. Ochib tahrirlang.
2

Static Mesh Component

  1. Components panel → Add → Static Mesh.
  2. Details → Static Mesh → Cube (Engine Content dan qidirish mumkin).
  3. Compile + Save.
3

Box Collision

  1. Add → Box Collision.
  2. Uni Static Mesh ga Parent qiling (drag under Mesh) — ixtiyoriy, lekin tavsiya.
  3. Box Extent yoki Scale ni biroz kattalashtiring — mesh atrofida “qalinroq” chegara.
4

Levelga 2–3 nusxa

  1. BP_TestObject ni Content Browser dan Viewport ga sudrang.
  2. Alt+drag yoki Copy-Paste bilan yana 1–2 ta.
  3. Har birida Location / Rotation / Scale ni o‘zgartirib ko‘ring.

05 Show Collision — chegara ko‘rinsin

Viewport da: Show (yoki View) → Collision. Yashil/binafsha wireframe — fizik chegara. Mesh dan biroz katta bo‘lishi normal; keyinroq Overlap osonroq ishlaydi.

Agar Collision umuman ko‘rinmasa: component tanlanganmi? Collision Enabled? Show Collision yoqilganmi?

★ Challenge

Point Light

Uchinchi component: Point Light. Intensity va Light Color ni o‘zgartiring. Levelda obyekt atrofida rangli nur ko‘rinsin — Component yana bir “qatlam” ekanligi seziladi.

★ Professor izohi

Unreal da “narsa” degani deyarli har doim Actor + Components. Ertaga shu Actor ichiga birinchi mantiq yozasiz. Bugun daraxtni to‘g‘ri o‘tkazsangiz — keyin script chalkashmaydi.
