Blueprint Communication

Ikki Actor qanday gaplashadi: avval Cast, keyin Blueprint Interface. Interaction System’ning poydevori shu yerda qo‘yiladi.

🎯 Kun maqsadi

Bugun siz:

  • → Ikkinchi Actor BP_TestObject2 yaratasiz
  • → Player’dan Cast To BP_TestObject orqali OnActivate chaqirasiz
  • → BPI_TestInterface yaratib, ichiga OnActivate qo‘shasiz
  • → Ikkala TestObject’ga interfeysni implement qilasiz
  • → Cast o‘rniga Interface Message ishlatasiz — bitta kod, ikkala obyekt

Bugun chuqurlashmang: Line Trace’ni to‘liq Interaction System darajasida yozmang (Kun 15). Hozircha sodda usul yetarli — masalan, yaqin Actor reference yoki oddiy Get All / overlap. Maqsad — Cast va Interface farqini his qilish.

📖 Asosiy tushunchalar

Object Reference

“Shu Actor’ga ishora” — o‘zgaruvchi yoki pin orqali boshqa Actor’ni ushlab turish. Reference bo‘lmasa, boshqa obyektning funksiyasini chaqira olmaysiz.

Cast

Umumiy Actor / Object reference’ni aniq turga aylantirish (masalan Cast To BP_TestObject). Muvaffaqiyatli bo‘lsa — o‘sha class’ning event/function’larini chaqirasiz. Muvaffaqiyatsiz — boshqa tarmoq (Cast Failed).

Kamchilik: har yangi tur (Door, Button, Light...) uchun alohida Cast tarmog‘i kerak → kod shishadi, “tight coupling”.

Blueprint Interface (BPI)

Shartnoma: “men OnActivate qila olaman” deb va’da beradigan funksiyalar to‘plami. Har xil Blueprint’lar shu interfeysni implement qiladi — har biri o‘zicha ichki mantiq yozadi. Chaqiruvchi tomon aniq class’ni bilishi shart emas: Interface Message yuboradi.

Interface Message

“Shu target’da BPI’ning OnActivate’ini ishga tushir” deb yuboriladigan chaqiruv. Target interfeysni implement qilgan bo‘lsa — ishlaydi; qilmagan bo‘lsa — odatda hech narsa bo‘lmaydi (xatosiz o‘tib ketishi mumkin).

Tight coupling

Player to‘g‘ridan-to‘g‘ri BP_Door, BP_Button, BP_Light... ni bilishi. Yangi obyekt qo‘shilsa Player kodi ham o‘zgaradi. Interface bilan Player faqat “Interact qiladigan narsa” ni biladi — yangi tur qo‘shish oson.

1

BP_TestObject2 yaratish

Taxminiy vaqt: 10 daqiqa

1.1 Nusxa yoki yangi Actor

Usul A (tez): Content Browser’da BP_TestObject ga o‘ng sichqoncha → Duplicate → nomini BP_TestObject2 qiling.

Usul B: Yangi Actor Blueprint yarating, Mesh + Collision qo‘shing, Event Graph’da OnActivate + Print (“TestObject2 faollashtirildi”) yozing — Kun 2–4 qisqacha takrori.

Muhim: ikkalasida ham chaqiriladigan OnActivate (yoki keyin Interface orqali bir xil nom) bo‘lsin.

1.2 Levelga ikkala obyekt

Level’ga BP_TestObject va BP_TestObject2 dan kamida bittadan joylashtiring. Bir-biridan uzoqroq qo‘ying — keyinroq qaysi biri ishlaganini ajratish oson.

Ixtiyoriy: Print matnlarini farqlang — “Object1” / “Object2”.

2

Cast usuli (vaqtinchalik)

Taxminiy vaqt: 25–35 daqiqa

2.1 Player Character’ni topish

Third Person template’da odatda:

Content/ThirdPerson/Blueprints/BP_ThirdPersonCharacter

(yoki loyihangizdagi asosiy Character). Uni oching → Event Graph.

Nima uchun Player: Input allaqachon Character’da ishlaydi. BP_TestObject’da E ishlashi uchun Enable Input kerak edi; Player’da bu muammo yo‘q.

2.2 Target reference olish (sodda variant)

To‘liq Line Trace Kun 15 da. Bugun o‘rganish uchun quyidagilardan birini tanlang:

Variant A — Instance Editable reference

  1. Character’da variable: TargetObject, tip: Object Reference → Actor (yoki BP_TestObject).
  2. Instance Editable / Expose on Spawn yoqing.
  3. Level’da Player Start / Character instance Details’da TargetObject sifatida BP_TestObject’ni tanlang.
  4. E Pressed → Cast / Call shu variable orqali.

Variant B — Get All Actors of Class (test uchun)

E Pressed → Get All Actors Of Class (BP_TestObject) → For Each → Cast (ixtiyoriy) → OnActivate. Barcha TestObject’lar birga ishlaydi — demo uchun qulay.

Variant C — qisqa Line Trace (ixtiyoriy oldindan)

Camera location → forward × 300 → Line Trace By Channel → Hit Actor. Keyin Cast. Bu Kun 15 ga yaqinroq; xohlasangiz sinab ko‘ring, lekin asosiy maqsad Cast/Interface.

2.3 Cast To BP_TestObject → OnActivate

E (yoki mavjud Interact) Pressed zanjirida:

  1. Target Actor pinidan (reference) sim torting.
  2. Cast To BP_TestObject qo‘shing (Object piniga reference ulang).
  3. As BP Test Object chiqishidan → OnActivate (Call) chaqiring.
  4. Cast Failed tarmog‘iga ixtiyoriy Print: “Bu TestObject emas”.

Play: Target to‘g‘ri BP_TestObject bo‘lsa — “Obyekt faollashtirildi”. BP_TestObject2 ga Cast To BP_TestObject odatda Failed bo‘ladi (boshqa class) — shu yerda Cast cheklovini ko‘rasiz.

Agar Duplicate qilgan bo‘lsangiz: BP_TestObject2 parent’i BP_TestObject bo‘lsa, Cast To BP_TestObject Success bo‘lishi mumkin (meros). To‘liq “boshqa tur” effekti uchun BP_TestObject2 ni alohida Actor qilib, o‘z OnActivate’iga ega qiling — yoki keyingi Interface bosqichida farqni ko‘ring.

3

BPI_TestInterface yaratish

Taxminiy vaqt: 10–15 daqiqa

3.1 Papka

Content/BetrayBuilder/Blueprints/ ichida Interaction papkasini yarating (yo‘q bo‘lsa).

3.2 Blueprint Interface asset

O‘ng sichqoncha → Blueprint Interface (Add → Blueprints → Blueprint Interface).

Nom: BPI_TestInterface

Ochilganda Functions ro‘yxati bo‘sh bo‘ladi.

3.3 OnActivate funksiyasini qo‘shish

Add (yoki + Function) → nom: OnActivate

Hozircha parametr shart emas (bo‘sh Input/Output). Keyinroq BPI_Interact da Instigator, Text, CanInteract qo‘shiladi (Kun 16).

Compile / Save interface asset’ni.

Eslatma: Interface’da faqat “imzo” (nom + pin’lar) bo‘ladi, ichki mantiq yo‘q. Mantiq har bir implement qiluvchi Blueprint’da yoziladi.

4

Interfeysni implement qilish

Taxminiy vaqt: 15–20 daqiqa

4.1 BP_TestObject

BP_TestObject’ni oching.

Toolbar: Class Settings (yoki Details’da class sozlamalari).

Interfaces → Implemented Interfaces → Add → BPI_TestInterface

Compile. My Blueprint / Interfaces ostida OnActivate paydo bo‘lishi mumkin.

Event Graph’da implementatsiya:

O‘ng sichqoncha → Event OnActivate (BPI_TestInterface) ni qo‘shing — yoki Interfaces ro‘yxatidan oching.

Bu event’ga avvalgi Custom Event OnActivate mantig‘ini ulashing (Print String), yoki Custom Event’ni olib tashlab, faqat Interface Event OnActivate ichida Print yozing.

Nom to‘qnashuvi: Custom Event ham OnActivate deb nomlangan bo‘lsa, chalkashishi mumkin. Eng toza yo‘l: Interface’dagi Event OnActivate ichida Print; eski Custom Event’ni Call o‘rniga Interface ishlatish.

4.2 BP_TestObject2

Xuddi shu: Class Settings → Implemented Interfaces → BPI_TestInterface.

Event OnActivate → Print String: masalan TestObject2 faollashtirildi

Compile + Save har ikkala Blueprint.

5

Cast o‘rniga Interface Message

Taxminiy vaqt: 15 daqiqa

5.1 Player Character’da o‘zgartirish

E Pressed zanjiridagi Cast To BP_TestObject ni olib tashlang yoki o‘chirib qo‘ying.

Target Actor (reference) pinidan:

  1. Qidiruv: OnActivate — ro‘yxatda OnActivate (BPI_TestInterface) / Message variantini tanlang.
  2. Yoki: Interface Message → BPI_TestInterface → OnActivate.
  3. Target piniga Actor reference’ni ulang (Cast’siz).

Endi kod BP_TestObject class’ini bilmaydi — faqat “OnActivate deb yubor” deydi.

5.2 Ikkala target bilan sinash

Reference’ni Level’da avval Object1, keyin Object2 ga qo‘ying (yoki Get All + For Each da Interface Message chaqiring).

Bitta xil chaqiruv — ikkala implementatsiya ham ishlashi kerak.

Test qilish

Taxminiy vaqt: 10 daqiqa

Kutilgan natija
  • ✓ Target = BP_TestObject → o‘z Print xabari
  • ✓ Target = BP_TestObject2 → o‘z Print xabari
  • ✓ Player kodida Cast To BP_TestObject yo‘q (yoki ishlatilmaydi)
  • ✓ Yangi tur qo‘shish = yangi Blueprint + implement BPI; Player’ni o‘zgartirish shart emas
