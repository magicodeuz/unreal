Stage 1 · Kun 4 / 7

Events va Functions

Custom Event va Function orqali kodni qayta ishlatiladigan qismlarga bo‘lishni o‘rganasiz. E tugmasi → OnActivate; GetDoubledValue funksiyasi.

🎯 Kun maqsadi

Bugun siz:

  • → Custom Event OnActivate yaratasiz
  • → E klaviatura eventini qo‘shib, undan OnActivate’ni chaqirasiz
  • → OnActivate ichida Print String chiqarasiz
  • → Function GetDoubledValue yozasiz — Integer kiradi, 2× qaytadi

Bugun qilmang: Enhanced Input System (Kun 6), boshqa Actor’lar bilan Cast/Interface (Kun 5). Faqat bitta Blueprint ichida Event va Function.

📖 Asosiy tushunchalar

BeginPlay

Actor Level’ga kirganda bir marta ishlaydi. Kecha ishlatgan edik.

Tick

Har freym (sekundiga ~60 marta) ishlaydi. Og‘ir hisoblashlar uchun ehtiyot bo‘ling — performance’ni yeydi. Bugun ishlatmaymiz, lekin bilib qo‘ying.

Custom Event

O‘zingiz yaratgan “signal”. Nom berasiz (masalan OnActivate), ichiga mantiq yozasiz, keyin istalgan joydan Call qilasiz. Bir mantiqni ko‘p joydan qayta ishlatish uchun qulay. Keyinchalik Interface va boshqa Actor’lar ham shu event’ni chaqirishi mumkin.

Function

Qayta ishlatiladigan mantiq bloki. Input parametrlari bo‘lishi mumkin, Return Value qaytarishi mumkin. Event’dan farqi: odatda “biror narsa hisobla / qaytar” uchun; pure function’lar side-effect’siz bo‘lishi mumkin.

Input Event

Klaviatura yoki sichqoncha tugmasi bosilganda/qo‘yib yuborilganda ishga tushadi. Bugun oddiy Keyboard Event: E ishlatamiz. Kun 6 da Enhanced Input (IA_Interact) ga o‘tamiz.

⚖️ Custom Event vs Function

Custom Event Function
Maqsad Signal / harakat (“faollashtir”) Hisoblash / qiymat qaytarish
Return Yo‘q (odatda) Bor (Return Value)
Qayerda Event Graph Alohida Function graph
Misol OnActivate GetDoubledValue

Ikkalasi ham “qayta chaqiriladigan” blok. Amaliyotda: “nima bo‘ldi” → Event; “qancha / qanday qiymat” → Function.

1.1 BP_TestObject → Event Graph

1.2 Custom Event yaratish

Bo‘sh joyda o‘ng sichqoncha → qidiruv: Custom Event

Yoki: Add Custom Event / Custom Event ni tanlang.

Node paydo bo‘ladi. Details panelida (yoki node ustida) Event Name ni o‘zgartiring:

OnActivate

Enter.

1.3 OnActivate ichida Print String

OnActivate’ning oq pin’idan sim torting → Print String

In String: Obyekt faollashtirildi

2

E tugmasi → OnActivate chaqirish

Taxminiy vaqt: 15 daqiqa

2.1 Keyboard Event: E

Event Graph’da o‘ng sichqoncha → qidiruv:

E yoki Keyboard Event → ro‘yxatdan E ni tanlang.

Ba’zi versiyalarda: Input Key → Key sifatida E tanlanadi.

Node’da Pressed / Released chiqishlari bo‘ladi. Pressed dan foydalanamiz.

2.2 Call OnActivate

E → Pressed pin’idan sim torting → bo‘sh joyga tashlang.

Qidiruvga yozing: OnActivate

Ro‘yxatda OnActivate (Call / Custom Event) chiqadi — tanlang.

Yoki: My Blueprint’da OnActivate’ni topib, graph’ga tashlang (Call varianti).

Nima bo‘ladi: E bosilganda execution OnActivate event’iga o‘tadi, u yerda Print String ishlaydi. Keyinchalik OnActivate ichiga eshik ochish, item olish kabi mantiq qo‘yiladi — chaqiruv joyi (E yoki Interaction) o‘zgarmasligi mumkin.

2.3 Enable Input (agar kerak bo‘lsa)

Agar Kun 3 da Enable Input qo‘ymagan bo‘lsangiz, E ishlamasligi mumkin.

BeginPlay zanjiriga qo‘shing:

  1. Enable Input
  2. Target: self
  3. Player Controller: Get Player Controller (Player Index = 0)

Compile + Save.

3

Function: GetDoubledValue

Taxminiy vaqt: 15–20 daqiqa

3.1 Yangi Function yaratish

Chap past — My Blueprint paneli.

Functions bo‘limi yonidagi + ni bosing.

Yangi function paydo bo‘ladi. Nom: GetDoubledValue

Enter. Editor avtomatik shu function’ning graph’iga o‘tishi mumkin (yoki Functions ro‘yxatidan ikki marta bosing).

3.2 Input parametr: Integer

Function graph’ida chapda Inputs / Details.

GetDoubledValue tanlangan holda Details’da:

Inputs → + yangi input.

  • Name: Value (yoki InputValue)
  • Type: Integer

Function entry node’ida endi yashil Integer pin ko‘rinadi.

3.3 Return Value: × 2

Details → Outputs → +

  • Name: odatda Return Value
  • Type: Integer

Graph’da o‘ng tomonda Return Node paydo bo‘ladi (yoki o‘zingiz qo‘shasiz: o‘ng sichqoncha → Return Node).

Mantiq:

  1. Entry’dagi Value pinidan sim torting.
  2. integer * integer (Multiply) qo‘shing — birinchi pin Value, ikkinchisiga 2 yozing.
  3. Multiply natijasini Return Node’ning Return Value pin’iga ulang.
  4. Entry’ning execution’ini Return’ning execution’iga ulang (function’larda ham oqim bor).

Tekshirish: Compile. Xato bo‘lmasa, function tayyor. Uni Event Graph’dan chaqirish mumkin.

3.4 (Ixtiyoriy) Function’ni sinab ko‘rish

Event Graph’ga qayting. BeginPlay yoki OnActivate yonida:

GetDoubledValue ni chaqiring → Value = 5 → Return’ni Print String (To String) orqali chiqaring. Play da “10” ko‘rinishi kerak.

Asosiy test E + OnActivate; function challenge’da to‘liq ishlatiladi.

★

Challenge

OnActivate + ClickCount + GetDoubledValue

OnActivate ichida:

  1. Agar ClickCount yo‘q bo‘lsa — Integer variable yarating (default 0).
  2. OnActivate boshida ClickCount’ni 1 ga oshiring (Get → +1 → Set), xuddi Kun 3 challenge’dagi kabi.
  3. GetDoubledValue chaqiring — Value piniga hozirgi ClickCount (oshirilgandan keyin) ulang.
  4. Return Value’ni To String qilib Print String’ga bering (yoki “Ikki baravar: ” + son).

Har E bosilganda: ClickCount o‘sadi, ekranda uning 2 baravari chiqadi (1→2, 2→4, 3→6...).
