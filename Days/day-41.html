Bugungi aniq maqsad

E_RoundState Enum + SetRoundState + Switch. Timer Playing da boshlansin; Win/Lose → Ending. Multiplayer va Betrayal uchun mustahkam asos.

01 Nima uchun State Machine?

Hozircha hamma narsa BeginPlay da ishga tushadi. Lekin haqiqiy o‘yinda: lobby kutish, rol tayinlash, keyin timer, keyin natija. Har bosqichda boshqa qoidalar ishlaydi — masalan Waiting da objective olinmasin.

Enum + SetRoundState = oddiy, o‘qiladigan state machine. Keyin har state uchun UI, audio, multiplayer replicate qo‘shiladi.

Professor eslatmasi

“If Playing then …” tarqoq if’lar o‘rniga bitta CurrentRoundState va SetRoundState — barcha o‘tishlar bir joyda. Bu debug va multiplayer sync uchun oltin qoida.

02 Nazariya — 5 ta holat

Holat Nima bo‘ladi
Waiting O‘yinchilar kutmoqda / lobby
Preparation Rol, spawn, qisqa tayyorgarlik
Playing Timer + objective + asosiy gameplay
Ending Win/Lose, timer stop, qisqa pauza
Results Yakuniy natija (keyin UI)

03 E_RoundState yaratish

  1. Content Browser → Content/BetrayBuilder/Data/
  2. Right-click → Blueprints → Enumeration → E_RoundState
  3. Enumerators: Waiting, Preparation, Playing, Ending, Results
  4. Save

04 CurrentRoundState + SetRoundState 

// BP_GameMode

Variables:
  CurrentRoundState (E_RoundState) — default Waiting

Function: SetRoundState(NewState: E_RoundState)
1. Branch: NewState == CurrentRoundState → Return (ixtiyoriy)
2. CurrentRoundState = NewState
3. Print String: "Round State: " + NewState
4. Switch on E_RoundState (NewState)
   - har pin uchun mos mantiq (quyida)

05 Switch — har holatning ishi 

// SetRoundState → Switch on NewState

Waiting:
  - Print "Waiting for players..."
  - (Challenge: player count check)

Preparation:
  - Print "Preparation..."
  - Qisqa Delay (2–3s) → SetRoundState(Playing)
  // yoki tugma / "ready" keyinroq

Playing:
  - RemainingTime = 600 (yoki 30 test)
  - Set Timer by Event (UpdateTimer)  // Day 38
  - Print "Playing — timer started"

Ending:
  - Clear Timer
  - Print Win yoki Lose xabari (bWon flag)
  - Delay (2–3s) → SetRoundState(Results)

Results:
  - Print "Results screen"
  - (keyin UI; hozircha kutish yoki Restart)

06 Win / Lose endi Ending orqali

OnGameWon / OnGameLost / EndGame endi to‘g‘ridan-to‘g‘ri “tugatish” emas:

  • bLastRoundWon = true/false saqlang
  • SetRoundState(Ending) chaqiring
  • Ending Switch pinida xabar + Clear Timer + keyin Results

BeginPlay: SetRoundState(Waiting) yoki to‘g‘ridan-to‘g‘ri Preparation (single-player test uchun). Test tezligi: Waiting ni o‘tkazib yuborish mumkin.
