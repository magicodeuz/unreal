? Nima uchun Light Switch?

Door — transform. Button — boshqa Actor. Light — rendering / atmosphere. Uchala tip interactable “oilasi”ni to‘ldiradi.

Social deduction o‘yinlarda qorong‘ulik = axborot kamayishi, stalk, sabotage. Texnik jihatdan light component’ni runtime’da boshqarish — asosiy skill.

Xuddi Door kabi: Player o‘zgarmaydi. Yangi BP + BPI implement.

💡 Set Visibility vs Set Intensity

Usul Nima qiladi Qachon
Set Visibility(false) Light “yo‘q” — odatda hisoblanmaydi To‘liq o‘chirish (tavsiya)
Set Intensity(0) Yorug‘lik 0, component hali bor Fade / dim / qisman
Set Visibility + Intensity Yoqilganda intensity tiklash Dimdan keyin to‘liq

Kurs nazariyasi: Visibility False = performance yaxshiroq. Intensity 0 ba’zan hali shadow/light cost saqlashi mumkin (engine versiyasiga qarab). Bugun Visibility toggle.

Silliq o‘chirish kerak bo‘lsa (keyinroq): Timeline Intensity 1→0, oxirida Visibility false.

🔆 Point Light — qisqa asoslar

Nuqtadan barcha yo‘nalishga yorug‘lik. Asosiy parametrlar:

  • Intensity — qanchalik yorqin (candela / unit engine’ga bog‘liq)
  • Attenuation Radius — ta’sir masofasi
  • Light Color — RGB / temperature
  • Cast Shadows — qimmatroq, chiroyli
  • Mobility — Stationary / Movable (runtime o‘zgarish uchun Movable yoki Stationary+toggle)

Mobility: Static light ba’zan runtime’da o‘chirishni cheklaydi. BP ichidagi Point Light odatda Movable yoki Stationary qiling — toggle ishlashi uchun.

Spot Light / Rect Light — keyinroq. Point eng oddiy.

Interact — toggle

6.1 Ikki usul

A — Branch aniq:

Interact
  → Branch bIsOn
       True:
         Set Visibility (Light, false)
         Set bIsOn false
       False:
         Set Visibility (Light, true)
         Set bIsOn true

Set bIsOn = NOT bIsOn
Set Visibility (Light, bIsOn)

? FAQ

Nima uchun Point, Spot emas?
Point oddiy, xona to‘ldirish uchun qulay. Spot — yo‘nalishli (lampa). Keyin qo‘shasiz.
Lumen / GI o‘chganda sekin yangilanadi?
Dynamic GI ba’zan kechikadi. Test uchun oddiy shading model yoki kichik xona. Production’da light channel / baked farq qilishi mumkin.
Ko‘p light performance?
Har dynamic light qimmat. Visibility off yordam beradi. Shadow o‘chirish ham.
