Bugungi aniq maqsad

Inventory’dan item’ni chiqarib, uni qaytadan dunyoga (levelga) joylashtirish. DropItem(Index): Array’dan Struct olish → Spawn BP_Item → ItemID o‘rnatish → Remove.

01 Nima uchun Drop kerak?

O‘yinchi Inventory to‘la bo‘lganda nima qiladi? Yoki keraksiz item’ni tashlamoqchim? Drop — bu erkinlik. Shuningdek, multiplayer va Betrayer mexanikasida “item tashlash” strategik bo‘lishi mumkin.

Texnik jihatdan Drop — Pickup’ning teskari amali. Pickup: Actor → ma’lumot → Array → Destroy Actor. Drop: Array → ma’lumot → Spawn Actor → Remove.

Professor eslatmasi

Simmetriya — yaxshi tizimning belgisi. Agar olinadigan narsa tashlab bo‘lmasa, o‘yinchi “cho‘ntak to‘la” tuzog‘iga tushadi. Drop bu tuzoqni ochadi. Bugun yozgan kod ertaga Consumable Remove uchun ham asos bo‘ladi.

02 Nazariya — ikki tomonlama oqim

Pickup (Day 30–31)
  1. Actor’dan ItemID olinadi
  2. S_ItemData yig‘iladi / Array.Add
  3. Destroy Actor
Drop (bugun)
  1. Array[Index] → S_ItemData
  2. Spawn BP_Item + Set ItemID
  3. Array.Remove Index

Day 32 tufayli Spawn qilingan Actor BeginPlay’da Data Table’dan Name/Icon ni o‘zi oladi. Siz faqat ItemID ni o‘rnatasiz — qolgani avtomatik.

03 DropItem(Index) — funksiya tuzilmasi 

// BP_Player → Function: DropItem
// Input: Index (Integer)

1. Branch: Index >= 0 AND Index < Length(InventoryArray)
   - False → return (xato index)

2. Get (InventoryArray, Index) → S_ItemData
3. Break S_ItemData → ItemID

4. Spawn Location hisoblash:
   - Get Actor Location (Player)
   - Get Actor Forward Vector * 100 (yoki 80)
   - Location = PlayerLoc + Forward*Offset
   - (ixtiyoriy) Z ni biroz ko'taring yoki Line Trace qiling

5. Spawn Actor from Class
   - Class: BP_Item
   - Spawn Transform: Location (Rotation = 0 yoki Player rotation)
   - Collision Handling: Try Adjust / Always Spawn

6. Spawned Actor da Set ItemID = Break.ItemID
   (Expose on Spawn bo'lsa — Spawn node da to'g'ridan-to'g'ri)

7. Remove Index (InventoryArray, Index)

8. Print String: "Tashlandi: " + ItemName

04 Spawn joylashuvi

Item Player ichiga yoki devorga tushmasligi kerak. Oddiy yechim:

  • Get Actor Location + Get Actor Forward Vector × 80–120
  • Z ni biroz oshirish (masalan +40) — yerga yaqin, lekin ichkariga kirib ketmasin

Challenge’da Line Trace bilan yerni topish tavsiya etiladi — item aniq yerga tushadi.

05 Array.Remove — tartib muhim

Avval ma’lumotni oling va Spawn qiling, keyin Remove qiling. Aks holda Index o‘zgarib ketishi yoki ma’lumot yo‘qolishi mumkin.

Remove Index dan keyin keyingi elementlarning indekslari siljiydi. Bir nechta item’ni ketma-ket tashlashda buni hisobga oling (hozircha bitta Drop yetarli).

06 Vaqtinchalik input — G tugmasi

UI hali yo‘q. Sinov uchun:

  • IA_Drop (yoki oddiy Keyboard G) qo‘shing
  • Bosilganda: agar InventoryArray Length > 0 bo‘lsa → DropItem(0) (birinchi item)
  • Yoki oxirgi item: DropItem(Length - 1)

Keyinchalik Inventory UI’dan tanlangan slot indeksi uzatiladi.

09 Keng tarqalgan xatolar

1. Spawn qilingan item “bo‘sh” / nom chiqmaydi

ItemID to‘g‘ri o‘rnatilganini tekshiring. BeginPlay Data Table’dan o‘qishi uchun ItemID Row Name bilan mos kelishi kerak (Day 32).

2. Item Player ichida yoki devorda spawn bo‘ladi

Forward offset ni oshiring (120–150). Collision Handling: Adjust If Possible. Challenge’dagi Line Trace yordam beradi.

3. Remove dan keyin noto‘g‘ri item tashlanadi

Avval Get qiling, Spawn qiling, keyin Remove. Remove ni Get dan oldin qilmang.

4. Index out of bounds

Funksiya boshida Index >= 0 va Index < Length tekshiruvini qo‘ying. Bo‘sh Inventory da Drop chaqirilmasin.
