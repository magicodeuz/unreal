04 Integration test rejasi

Yangi feature yo‘q. Faqat to‘liq tsikl va topilgan xatolarni tuzatish.

A

Round boshlanishi

  1. Play → Waiting / Preparation → Playing
  2. Timer ishga tushadi (Print yoki log)
  3. CurrentRoundState to‘g‘ri o‘zgaradi
B

Item + Objective zanjiri

  1. Key oling → qulflangan eshik ochilsin
  2. Battery oling → Generator Interact → Objective complete
  3. Manager Array da IsCompleted true
C

Win va Lose

  1. Barcha objective → Ending → BUILDERS WIN
  2. Qisqa timer, objective’siz → TIME’S UP LOSE
  3. Input o‘chadi, timer to‘xtaydi, state Results

05 Win yo‘li (qo‘llanma)

  1. Round Playing ga o‘tadi, timer ishlaydi
  2. Key item oling (Inventory)
  3. Qulflangan eshik / xona oching
  4. Battery oling → Generator ga olib boring → Interact
  5. Barcha objective’lar complete
  6. OnGameWon / SetRoundState(Ending) → “BUILDERS WIN!”
  7. Results holati

06 Lose yo‘li (qo‘llanma)

  1. RemainingTime ni 20–30 s qiling (test)
  2. Objective bajarmang
  3. OnTimeUp → OnGameLost → “TIME’S UP — BUILDERS LOSE!”
  4. Ending → Results
  5. Test tugagach RemainingTime ni 600 ga qaytaring

07 Tipik xatolar va tuzatish

Timer Playing dan oldin ishlaydi / ikki marta

Timer faqat SetRoundState(Playing) ichida start. BeginPlay da to‘g‘ridan-to‘g‘ri Set Timer yo‘q. Handle Clear qiling.

Objective complete bo‘lmaydi / Win kelmaydi

ItemID, Manager Array, MarkObjectiveComplete, AreAllObjectivesComplete zanjirini Print bilan tekshiring. GameMode Cast.

Interact / Pickup ishlamaydi

BPI_Interact, collision, Line Trace, Inventory capacity. Faqat Playing da o‘ynashga ruxsat berish (ixtiyoriy guard).

State “yopishib” qoladi

Har o‘tishda Print CurrentRoundState. Ending → Results Delay ishlayotganini tekshiring. bGameEnded flag.
