Stage 2 · Kun 10 / 14

Sprint

Left Shift bosib turib yugurish: Max Walk Speed 300 ↔ 600. IsSprinting state.

🎯 Kun maqsadi

  • → Kun 6 dagi IA_Sprint ni haqiqiy mantiqqa ulash
  • → Started → Max Walk Speed = 600
  • → Completed → Max Walk Speed = 300
  • → Boolean IsSprinting yangilash (keyinroq UI / State)

Bugun qilmang: Stamina, charchash, sprint animatsiyasi (Day 13+). Faqat tezlik va flag.

📖 Asosiy tushunchalar

Set Max Walk Speed

Runtime’da Character Movement Component tezligini o‘zgartiradi. Alohida “sprint component” shart emas — faqat raqamni yozasiz.

Hold (bosib turish)

Started = Shift bosildi; Completed = qo‘yib yuborildi. Toggle (bir marta bosib yoq/o‘chir) emas — ko‘pincha o‘yinlarda sprint hold.

IsSprinting

Boolean state. Animatsiya, UI, keyinroq stamina “sprint paytidami?” deb so‘raydi. Tezlikdan mustaqil flag saqlash yaxshi odat.

↗ Mantiq sxemasi 

IA_Sprint (Started)
    │
    ├─ Set Max Walk Speed (600)
    └─ Set IsSprinting = true

IA_Sprint (Completed)
    │
    ├─ Set Max Walk Speed (300)
    └─ Set IsSprinting = false

⚙️ Oldindan talab

  • ✓ Kun 9: WASD + Jump ishlaydi
  • ✓ IA_Sprint + IMC’da Left Shift (Kun 6)
  • ✓ BP_Player’da Mapping Context ulangan
  • ✓ Default Max Walk Speed ≈ 300
1

IA_Sprint tekshirish

Taxminiy vaqt: 5 daqiqa

1.1 Asset va mapping

Input papkasida IA_Sprint borligini tekshiring (Digital).

IMC_BetrayBuilder: Left Shift → IA_Sprint.

Yo‘q bo‘lsa — Kun 6 bo‘yicha qayta yarating va map qiling.

BP_Player Event Graph’da eski Print String bo‘lsa (Kun 6 test) — o‘chirib, haqiqiy mantiqqa almashtirasiz.

2

IsSprinting variable

Taxminiy vaqt: 5 daqiqa

2.1 Boolean qo‘shish

BP_Player → My Blueprint → Variables → +

  • Name: IsSprinting
  • Type: Boolean
  • Default: false

Compile (variable graph’da ko‘rinsin).

Instance Editable: Hozircha shart emas. Keyinroq UI yoki boshqa Blueprint o‘qishi uchun Get qilinadi.

3

Started / Completed mantiq

Taxminiy vaqt: 15–20 daqiqa

3.1 IA_Sprint event node

Event Graph → qidiruv: IA_Sprint → Enhanced Input Action IA_Sprint.

3.2 Started — sprint yoqish

Started pinidan:

  1. Get Character Movement (yoki Components’dan Character Movement reference)
  2. Set Max Walk Speed → Target = Character Movement, New Max Walk Speed = 600
  3. Set IsSprinting = true

Set Max Walk Speed ba’zan to‘g‘ridan-to‘g‘ri Character’da ham chiqadi (internal movement’ga yozadi).

3.3 Completed — oddiy tezlik

Completed pinidan:

  1. Set Max Walk Speed = 300
  2. Set IsSprinting = false

Compile + Save.

Magic numbers: 300 va 600 ni keyinroq variable (WalkSpeed / SprintSpeed) qilish yaxshi amaliyot. Bugun literal yetarli.

4

Test qilish

Taxminiy vaqt: 10 daqiqa

Play
  1. WASD bilan oddiy yurish (tezlik ~300).
  2. Left Shift bosib turing + WASD — sezilarli tezroq (~600).
  3. Shift ni qo‘ying — yana oddiy tezlik.

Muvaffaqiyat: Sprint ishlaydi; IsSprinting state yangilanadi.

Ishlamasa: IA_Sprint event Started/Completed ulanganmi? IMC’da Shift → IA_Sprint? Set Max Walk Speed to‘g‘ri component’ga yozilganmi? Boshqa joy 300 ni qayta yozmayaptimi?

★

Challenge

Debug “Running”

IsSprinting true bo‘lganda ekranda “Running” ko‘rinsin (debug).

Masalan: Event Tick → Branch (IsSprinting) → True → Print String (“Running”, short duration) — yoki faqat Started’da bir marta Print, Completed’da “Walking”.

Tick + Print har freym shovqinli bo‘lishi mumkin; qisqa Duration yoki faqat o‘tishlarda Print qiling.
