Blueprint asoslari

Birinchi Event Graph. Quyida har bir oqim UE5 dagi kabi node sxemasi bilan — ko‘rib, Editor da takrorlang.

Bugungi aniq maqsad

BeginPlay → Print String. Boolean + Branch + Left Mouse. Sxemani o‘qing, keyin pinlarni ulang.

01 Event Graph — nima bu?

BP_TestObject → Event Graph. Rangli quti = Node. Oq chiziq = execution. Rangli chiziq = ma’lumot. Node qo‘shish: o‘ng tugma → qidiruv (Print String, Branch…).

02 Pin turlari — ranglar

Execution— oq strelka

Integer— butun son
Float— kasr
String— matn

Qoida: exec faqat exec ga. Boolean ni Integer piniga ulang — chalkashadi.

04 Sxema 1 — BeginPlay → Print String

Play bosilganda Actor dunyoga kiradi → BeginPlay bir marta. Undan Print String.

Qanday qo‘shiladi:

2) Print String: o‘ng tugma → print → Print String
3) BeginPlay o‘ng oq pin → Print String chap oq pin
4) In String maydoniga: Salom, BetrayBuilder!

05 Sxema 2 — Left Mouse + IsPressed + Branch

Boolean IsPressed (default false). Pressed → true + Branch. Released → false.

BP_TestObject · Mouse flow
Left Mouse Button Pressed
→
SET IsPressed Value = true
→
Branch Condition ← GET IsPressed
True →
Print String · "Bosildi"
False →
Print String · "Bosilmadi"
Left Mouse Button Released
→
SET IsPressed Value = false
Condition = Boolean pin True / False = exec chiqishlari
Qanday yig‘iladi:
1) + Variable → IsPressed (Boolean)
2) O‘ng tugma → Left Mouse Button
3) Pressed → Set IsPressed (true) → Branch (Condition = Get IsPressed)
4) True → Print "Bosildi" · False → Print "Bosilmadi"
5) Released → Set IsPressed (false)

Input Actor da ishlamasa — Character da xuddi shu sxemani yozing. Maqsad: Branch + Boolean.
