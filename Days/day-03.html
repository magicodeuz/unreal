Stage 1 · Kun 3 / 7

Blueprint asoslari

Event Graph, node, pin, execution flow va o‘zgaruvchilar — birinchi marta qo‘lda ishlaydigan mantiq yozasiz.

🎯 Kun maqsadi

Bugun siz:

  • → Event Graph ni ochib, unda ishlashni o‘rganasiz
  • → BeginPlay → Print String zanjirini ulang
  • → Boolean variable yaratasiz
  • → Sichqoncha bosilganda Branch orqali turli xabar chiqarasiz
  • → Node, execution pin va data pin farqini amalda ko‘rasiz

Bugun qilmang: Custom Event, Function yaratish, Cast — bular keyingi kunlar. Faqat asosiy node’lar bilan ishlang.

📖 Asosiy tushunchalar

Event Graph

Blueprint’ning vizual dasturlash maydoni. Bu yerda node’larni joylashtirib, ularni simlar bilan bog‘laysiz. “Kod” o‘rniga grafik.

Node

Bitta amal yoki funksiya. Masalan: Print String (ekranga matn chiqaradi), Branch (shart tekshiradi), Set (variable’ga qiymat yozadi). Har node’ning kirish/chiqish pin’lari bor.

Execution pin (oq / oq strelka)

Qaysi node keyin ishga tushishini bildiradi. Chapdagi oq uchburchak — “menga kel”, o‘ngdagi — “keyingisiga o‘t”. Execution oqimi chapdan o‘ngga ketadi.

Data pin (rangli)

Qiymatlarni bir node’dan ikkinchisiga uzatadi. Rang tipga bog‘liq: Boolean qizil, Integer/Float yashil, String binafsha, Object ko‘k va h.k. Faqat bir xil tipdagi pin’lar ulanadi.

Variable

Qiymat saqlaydigan nomli konteyner. Asosiy turlar:

  • Boolean — true / false
  • Integer — butun son (0, 1, −5, 100)
  • Float — kasr son (0.5, 3.14)
  • String — matn (“Salom”)
BeginPlay

Actor dunyoga (Level’ga) kirganda bir marta ishga tushadigan event. “O‘yin boshlandi, men paydo bo‘ldim” signali.

Branch

Shartli ajratish. Condition (Boolean) true bo‘lsa — True chiqishidan, false bo‘lsa — False chiqishidan davom etadi. Dasturlashdagi if / else ga o‘xshaydi.

🔌 Pin ranglari (eslab qoling)

Rang Tip Misol
Oq Execution Oqim yo‘nalishi
Qizil Boolean true / false
Yashil Integer / Float 42, 3.14
Binafsha String "Salom"
Ko‘k Object / Actor Reference

1

Event Graph’ni ochish

Taxminiy vaqt: 3–5 daqiqa

1.1 BP_TestObject’ni oching

Content Browser’da Content/BetrayBuilder/Blueprints/BP_TestObject ni toping.

Ikki marta bosing — Blueprint Editor ochiladi.

1.2 Event Graph tab’iga o‘ting

Blueprint Editor yuqorisida (yoki o‘rtada) tab’lar bor:

  • Viewport — 3D ko‘rinish (Kun 2 da ishlatgan edik)
  • Event Graph ← mana shuni bosing
  • Construction Script, va boshqalar

Event Graph ochilganda katta to‘r (grid) maydoni chiqadi. Ba’zan allaqachon Event BeginPlay va Event Tick node’lari turgan bo‘ladi (template yoki default).

Navigatsiya: O‘ng sichqoncha + sudrash — maydonni siljitish. Scroll — zoom. Bo‘sh joyda o‘ng sichqoncha — node qidiruv menyusi.

2

BeginPlay → Print String

Taxminiy vaqt: 10–15 daqiqa

2.1 BeginPlay node’ini topish yoki yaratish

Agar Event Graph’da allaqachon Event BeginPlay bo‘lsa — undan foydalaning.

Yo‘q bo‘lsa:

  1. Bo‘sh joyda o‘ng sichqoncha bosing.
  2. Qidiruvga yozing: BeginPlay
  3. Event BeginPlay ni tanlang.

Qizil/to‘q sariq rangli event node paydo bo‘ladi. O‘ng tomonida bitta oq execution pin (chiqish) bor.

2.2 Print String node qo‘shish

Usul A (tavsiya): BeginPlay’ning o‘ngdagi oq execution pinidan simni torting (chap sichqoncha bosib sudring) va bo‘sh joyga tashlang. Avtomatik qidiruv ochiladi.

Yozing: Print String → tanlang.

Usul B: Bo‘sh joyda o‘ng sichqoncha → Print String qidirib qo‘shing, keyin BeginPlay execution’ini Print String’ning chapdagi execution pin’iga ulang.

Ulanish: Oq pin → oq pin. Agar sim qizil bo‘lib qolsa yoki ulanmasa — tip mos kelmayapti demak (execution’ni data pin’ga ulashga urinmang).

2.3 Matnni o‘zgartirish

Print String node’ida In String maydoni bor (binafsha pin yoki to‘g‘ridan-to‘g‘ri matn qutisi).

Default odatda “Hello” yoki bo‘sh. Uni o‘chirib yozing:

Salom, BetrayBuilder!

Boshqa sozlamalar (Print to Screen, Text Color, Duration) hozircha default qolsin — ekranda ko‘rinishi uchun Print to Screen yoqilgan bo‘lishi kerak (odatda default yoqilgan).

2.4 Compile + Save

Compile bosing. Xato bo‘lmasa yashil belgi chiqadi.

Save (Ctrl+S).

Hozircha tekshirish: Keyinroq Play qilganda Level ochilishi bilan yuqori chapda (yoki ekranda) “Salom, BetrayBuilder!” chiqishi kerak. Hozir input qismini ham yozib, keyin birga test qilamiz.

3

Boolean variable yaratish

Taxminiy vaqt: 5–10 daqiqa

3.1 My Blueprint panelidan variable qo‘shish

Blueprint Editor’ning chap pastki qismida My Blueprint paneli bor.

Ichida Variables bo‘limini toping.

Yonidagi + tugmasini bosing (yoki Variables ustida o‘ng sichqoncha → Add Variable).

Yangi variable paydo bo‘ladi. Nomini o‘zgartiring: IsPressed

Enter bosing.

3.2 Tipni Boolean qilish

IsPressed tanlangan holatda o‘ngdagi Details paneliga qarang.

Variable Type — default odatda Boolean bo‘ladi. Agar boshqacha bo‘lsa:

Dropdown’ni oching → Boolean ni tanlang.

Default Value: false (bo‘sh / unchecked) qoldiring.

Compile eslatmasi: Variable qo‘shgach yoki tipini o‘zgartirgach Compile qiling — aks holda Event Graph’da Get/Set to‘g‘ri ishlamasligi mumkin.

4

Input event + Branch

Taxminiy vaqt: 20–25 daqiqa

4.1 Left Mouse Button event

Event Graph’da bo‘sh joyda o‘ng sichqoncha → qidiruv:

Left Mouse Button

Yoki: Mouse → ro‘yxatdan Left Mouse Button event’ini tanlang.

Node’da odatda ikkita execution chiqishi bo‘ladi:

  • Pressed — tugma bosilganda
  • Released — qo‘yib yuborilganda

Biz Pressed dan foydalanamiz.

Eslatma: Bu input Actor’ga “Enable Input” va Player Controller bog‘langan bo‘lishi kerak. Test paytida ba’zan ishlamasligi mumkin — pastda yechim beriladi. Hozircha graph’ni to‘liq yozib chiqing.

4.2 Set IsPressed = true

My Blueprint → Variables → IsPressed ni Event Graph’ga sudrab tashlang.

Menyu chiqadi: Get yoki Set.

Set ni tanlang.

Left Mouse Button → Pressed execution pin’ini Set IsPressed’ning chapdagi execution pin’iga ulang.

Set node’ida Boolean qiymat maydoni bor — belgini qo‘ying (true).

4.3 Branch qo‘shish

Set IsPressed’ning o‘ng execution pin’idan sim torting → bo‘sh joyga tashlang → yozing: Branch

Yoki o‘ng sichqoncha → Branch.

Branch’da:

  • Chapda: execution kirish + Condition (qizil Boolean pin)
  • O‘ngda: True va False execution chiqishlari

Condition’ga IsPressed ulash:

Yana IsPressed’ni graph’ga tashlang → bu safar Get ni tanlang.

Get IsPressed’ning qizil chiqish pin’ini Branch’ning Condition pin’iga ulang.

4.4 True / False ga Print String

Branch → True pin’idan sim torting → Print String

In String: Bosildi

Branch → False pin’idan sim torting → yana Print String

In String: Bosilmadi

Pressed zanjirida biz IsPressed’ni true qilganimiz uchun odatda har doim “Bosildi” chiqadi. False tarmog‘i Released yoki boshqa mantiq uchun tayyor turadi — tushunish uchun ikkalasini ham yozib qo‘yamiz.

4.5 (Tavsiya) Released’da false qilish

Left Mouse Button → Released dan:

Set IsPressed → qiymatni false (belgisiz) qiling.

Bu “bosib turib / qo‘yib yuborish” holatini to‘g‘ri kuzatadi. Keyinroq Sprint, Interact kabi joylarda shu naqsh ishlatiladi.

Compile + Save.

5

Test qilish

Taxminiy vaqt: 10 daqiqa

Play
  1. Level’ga qayting (BP_TestObject instance’i joylashgan).
  2. Play (yoki Alt+P) bosing.
  3. Darhol ekranda (odatda yuqori chap) Salom, BetrayBuilder! chiqishi kerak — BeginPlay ishladi.
  4. Chap sichqonchani bosing — Bosildi chiqishi kerak.

Muvaffaqiyat mezonlari:

  • ✓ Level ochilganda “Salom, BetrayBuilder!” ko‘rinadi
  • ✓ Sichqoncha bosilganda “Bosildi” chiqadi
  • ✓ Node, pin va execution flow tushunilgan
Agar sichqoncha ishlamasa

Actor default holda input qabul qilmasligi mumkin. Ikki yechim:

Yechim A — Enable Input (BeginPlay’da)

  1. BeginPlay zanjiriga (Print String’dan oldin yoki keyin) Enable Input qo‘shing.
  2. Target: Self (BP_TestObject).
  3. Player Controller: Get Player Controller (index 0) ni ulang.

Yechim B — vaqtincha Player’da sinash

Input’ni Character Blueprint’da yozish osonroq (u allaqachon input oladi). Bugun o‘rganish uchun BP_TestObject yetarli; ishlamasa Enable Input qo‘shing.

Output Log: Print String ba’zan faqat Output Log’da ko‘rinadi. Window → Developer Tools → Output Log. Yoki Print String’da “Print to Screen” yoqilganiga ishonch hosil qiling.

★

Challenge — ClickCount

Integer variable + hisoblash

Har bosishda sonni oshiring va chiqaring:

  1. Yangi variable: ClickCount, tip: Integer, default 0.
  2. Compile qiling.
  3. Left Mouse Button → Pressed zanjirida (IsPressed Set’dan keyin yoki o‘rniga):
    • Get ClickCount
    • Integer + Integer (yoki Add) — Get natijasiga 1 qo‘shing
    • Set ClickCount — yig‘indi ni yozing
    • Print String — lekin sonni matn qilish kerak: To String (Integer) yoki Print String o‘rniga to‘g‘ridan-to‘g‘ri Format / Append ishlating
  4. Oddiy yo‘l: Set ClickCount’dan keyin Print String, In String’ga Append yoki Format Text orqali “Bosishlar: ” + ClickCount ulang. Yoki Get ClickCount → To String → Print String.

Play qilib bir necha marta bosing — 1, 2, 3... o‘sishi kerak.
